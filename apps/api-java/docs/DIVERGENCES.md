# 의도적 차이 대장

Nest 구현과 **일부러 다르게** 만든 지점을 기록한다.

이 파일이 존재하는 이유: 파일럿의 목표는 동작 동일성인데, 몇 군데는 동일하게 만들면 안 되는
곳이 있다(현행이 결함이라서). 그런 결정을 코드 주석에만 남기면 나중에 "왜 다르지?"가 "버그
아닌가?"로 읽힌다. 차이는 전부 여기에 이유와 함께 적는다.

**기입 규칙**

- 골든 대조에서 diff 가 나면 → 반드시 여기 한 줄이 있거나, 아니면 그건 버그다. 예외 없음.
- "더 나아 보여서" 는 사유가 아니다. 무엇이 깨지는지 / 무엇이 안 깨지는지를 적는다.
- 프론트가 보는 응답 모양을 바꾸는 차이는 **금지**한다. 계약을 바꾸는 건 파일럿 범위 밖이다.
  바꿔야 할 것 같으면 여기 적는 대신 파일럿을 멈추고 논의한다.

## 대장

| # | 지점 | Nest | 파일럿 | 사유 | 프론트 영향 |
|---|---|---|---|---|---|
| D-1 | 잔액 갱신 경로의 행 잠금 | `spend`/`exchange` 만 잠금. `grant`/`redeem`/`refund` 는 잠금 없음 | 5경로 전부 잠금 | 잠금 없는 3경로는 동시 요청에서 read-modify-write 가 겹쳐 잔액이 실제보다 커진다(= 실질 무료 구매). 재현 테스트는 `LostUpdateReproductionTest` | 없음. 응답 모양 동일 |

> 아직 W1 이라 D-1 외에는 비어 있다. 구현이 진행되면 여기가 채워진다.
> 비어 있는 게 정상이 아니라, **채워지지 않는 게 정상**이다 — 차이는 적을수록 좋다.

## 차이가 아닌 것 (기록해 두는 혼동 지점)

아래는 "달라 보이지만 같아야 하는" 것들이다. 여기 있는 항목이 골든에서 diff 로 나오면 버그다.

| 지점 | 주의 |
|---|---|
| `progressRatio` | 정수값일 때 `1` 이지 `1.0` 이 아니다. Java `double` 그대로 내면 깨진다 |
| 날짜 | `2026-07-20T07:21:56.727Z` — 밀리초 3자리 고정. `Instant.toString()` 은 ms 가 0 이면 `.000` 을 생략한다 |
| null 반환 엔드포인트 | 빈 바디 200 이다. `{}` 도 `null` 도 아니다 |
| `shop_item.payload` | JSON 통과(passthrough). 문자열로 감싸면 프론트의 `typeof payload !== 'object'` 가드에 걸려 코스메틱이 조용히 죽는다 |
| 401 봉투 | `{success, timestamp, path, method, statusCode, error:{name,message,details}, requestId}`. Spring 의 `ProblemDetail` 로 바꾸면 프론트의 `/auth/refresh` 자동 재시도가 죽는다 |
| `DATETIME` 존 해석 | **UTC**다. 서버 `time_zone` 이 `+09:00` 이어도 그렇다 — 규약을 정한 건 서버가 아니라 Prisma다. `Asia/Seoul` 로 읽으면 9시간 어긋난다. ADR-0002 |
| 토큰 추출 순서 | 쿠키 `access_token` **먼저**, 그 다음 `Authorization: Bearer`. 반대로 하면 계정 전환 직후 둘이 다른 계정을 가리킬 때 Nest와 판정이 갈린다 |
| 에러 메시지 한국어 | `계정을 찾을 수 없습니다` 등을 그대로 쓴다. 프론트가 토스트에 그대로 띄우므로 영어로 바꾸면 사용자 화면이 바뀐다 |
| P2002(중복) 정책 비대칭 | `exchange`/`grant`/`purchase` 는 흡수 후 200, `redeem`/`refund` 는 409. 뭉개서 통일하면 프론트 재시도 UX 가 깨진다 |
| `wallet_ledger.reason` enum | 미사용 2값(`PURCHASE_TOPUP`, `ADMIN_ADJUST`) 포함 7값 전부 선언. 좁히면 기존 행 조회에서 예외가 난다 |
| `refund` 멱등키 | `REVERSAL:{itemId}`. `{ledgerId}` 로 "개선" 하면 환불의 환불이 무한 증폭된다 |
