# 국가 선택 시 "대시보드" 네이밍 검토

## 현재 화면 구조

국가를 선택하면 **우측 상세**에 다음 구조가 나옵니다.

### 1단계: 메인 탭 (CountryDetailTabs)
| 탭 ID   | 라벨       |
|--------|------------|
| overview | **대시보드** |
| people   | 인물       |
| military | 군대       |
| events   | 주요 사건  |

### 2단계: "대시보드"(overview) 선택 시에만 보이는 서브탭 (OverviewSubTabs)
| 서브탭 ID        | 라벨               |
|------------------|--------------------|
| statistics       | **대시보드**       |
| linkedHistorical | 연결된 역사적 국가 |
| map              | 지도 및 지역       |
| government       | 행정조직           |
| ethnicity        | 민족               |
| person           | 인물               |
| history          | 역사               |

### 서브탭 "대시보드"(statistics)에서 보이는 실제 콘텐츠
- **요약 지표 카드만** (한눈에 보기): 인물 수, 군대 수, 주요 사건 수, 연결된 역사적 국가 수.
- 상세는 각 메인·서브 탭에서 확인.

### 서브탭 "연결된 역사적 국가"(linkedHistorical)에서 보이는 콘텐츠
- **LinkedHistoricalCountriesSection**: 목록 | 흐름도, 변천·소속·수평 관계.

## 검토 결과

### 1. "대시보드"라는 이름이 적절한가?
- **콘텐츠 성격**: 해당 국가의 연결 역사적 국가, 요약 지표, 변천/관계를 한 화면에 보여줌 → **한국 한눈에 보기**에 맞는 대시보드 성격임.
- **결론**: 이 화면을 "대시보드"로 부르는 것은 **적절함**.

### 2. 문제: 이중 "대시보드"
- **메인 탭**: "대시보드" (overview)
- **그 안 첫 서브탭**: "대시보드" (statistics)
- → **"대시보드 > 대시보드"** 로 같은 단어가 두 번 나와 구분이 잘 안 됨.

### 3. 권장 옵션

| 옵션 | 메인 탭 라벨 | 서브 첫 탭 라벨 | 비고 |
|------|--------------|-----------------|------|
| **A** | 대시보드 (유지) | **요약** 또는 **통계·요약** | 서브만 구체적으로 변경. "대시보드 > 요약"으로 의미 명확. |
| **B** | **개요** | 대시보드 (유지) | 메인을 "개요"로 하면 "개요 > 대시보드"로 자연스러움. |
| **C** | 대시보드 (유지) | **통계 및 지표** (원복) | 이전처럼 통계/지표 강조. |

**추천**: **옵션 A** — 메인은 "대시보드"로 두고, 서브 첫 탭만 **"요약"**으로 두면  
- "대시보드(메인) = 이 국가의 전체 개요 영역"  
- "요약(서브) = 그중에서도 한눈에 보는 요약/지표 화면"  
으로 계층이 분명해짐.

---

## 요약
- **"대시보드"에 보이는 내용**은 한 국가 요약/지표/역사적 국가 연결이라 **대시보드라고 부르는 것은 적절**함.
- 다만 **메인·서브 모두 "대시보드"**라서 중복이므로, **서브 첫 탭만 "요약" 등으로 바꾸는 것**을 권장함.
