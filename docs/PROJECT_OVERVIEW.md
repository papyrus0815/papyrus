## 1. 프로젝트 개요

### 1.1 프로젝트명
**Papyrus** (파피루스)

### 1.2 한 줄 설명
**사용자가 직접 역사·현대 정보를 입력**하고, **사용자 간 지식을 공유**하는 **집단지성 기반 시사·역사 데이터 플랫폼**

> 💡 **핵심 차별점**: 
> - 모든 정보는 **사용자가 직접 입력** (UGC 기반)
> - 향후 **사용자 간 정보 교환 및 협업** 기능 제공
> - 역사부터 **현대 사건까지** 통합 관리

### 1.3 프로젝트 배경

현대 사회에서 역사 정보는 다음과 같은 문제점을 가지고 있습니다:

#### 문제점
- 📚 **분산된 정보**: 역사 정보가 여러 플랫폼에 흩어져 있어 통합 관리 어려움
- 🔍 **비구조화된 데이터**: 위키피디아 등은 자유 형식으로, 체계적인 데이터 분석 불가
- 🌐 **관계 파악 어려움**: 사건-인물-국가-조직 간 복잡한 관계를 직관적으로 이해하기 어려움
- ⏰ **시간적 흐름 추적 곤란**: 역사적 사건의 원인과 결과를 시계열로 추적하기 어려움
- 🎓 **교육용 활용 제한**: 기존 자료는 교육/연구 목적의 체계적 활용에 한계
- 👥 **참여 장벽**: 전문가만 정보를 생산할 수 있는 구조

#### 해결 방안
Papyrus는 이러한 문제를 해결하기 위해:
- ✅ **사용자 직접 입력**: 누구나 역사·현대 정보를 구조화하여 입력 가능
- ✅ **집단지성 기반**: 여러 사용자가 함께 지식을 축적
- ✅ 사건-인물-조직 간 관계를 자동으로 연결
- ✅ 시각적 그래프로 복잡한 관계를 직관적으로 표현
- ✅ 시계열 기반 타임라인으로 인과관계 추적
- ✅ API 제공으로 다양한 교육/연구 서비스에 활용 가능
- ✅ **향후 사용자 간 정보 교환**: 소셜 기능으로 지식 공유 활성화

### 2.3 시장 트렌드

#### 기존 트렌드
- 📈 **디지털 전환**: 문화유산의 디지털화 가속 (2024년 문화재청 예산 증가)
- 📈 **에듀테크 성장**: 온라인 교육 시장 연평균 15% 성장
- 📈 **데이터 기반 의사결정**: 체계화된 데이터의 중요성 증가
- 📈 **시각화 니즈**: 복잡한 정보를 직관적으로 이해하려는 수요 증가

#### 현대 정보 관련 신규 트렌드 🆕
- 📈 **팩트체크 중요성**: 가짜뉴스 증가로 정확한 정보 구조화 필요
- 📈 **지정학적 리스크 관리**: 
  - 미중 갈등, 러우 전쟁 등 국제 정세 복잡화
  - 기업/투자자의 지정학적 리스크 분석 수요 급증
- 📈 **실시간 정보 니즈**: 
  - 빠르게 변하는 국제 정세
  - 정책 변화에 대한 즉각적 대응 필요
- 📈 **관계 분석 도구**: 
  - 복잡한 국제 관계 이해
  - 동맹/적대 관계의 시각화
- 📈 **역사적 맥락의 중요성**:
  - 현재 사건을 이해하기 위한 역사적 배경 필요
  - "역사는 반복된다" - 패턴 분석 수요
