# Papyrus 프로젝트 개요서

> **과거부터 현재까지, 모든 사건과 관계를 연결하는 지능형 플랫폼**

**작성일**: 2024년 12월 30일 | **버전**: 2.0.0  
**분류**: IT/소프트웨어, 빅데이터, 에듀테크, 디지털 콘텐츠

---

## 1. 프로젝트 개요

### 핵심 개념
**역사적 사건부터 현대 시사까지**, 사건·인물·국가·조직 간의 복잡한 관계를 **사용자가 직접 구조화**하여 관리하고 시각화하는 **크라우드소싱 기반 지식 플랫폼**

### 차별점
```
기존 서비스                    Papyrus
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
위키피디아    자유 형식       →  구조화된 데이터
뉴스 DB      현재만          →  역사+현재 통합
학술 DB      논문만          →  모든 사건 포괄
타임라인 앱  시각화만        →  관계 분석 + 시각화
전문가만 편집              →  사용자 기여 (향후 소셜)
```

### 시간적 범위
- **과거**: 고대부터 20세기까지
- **현재**: 21세기 실시간 사건 (트럼프 정책, 미중 갈등 등)
- **연결**: 역사적 맥락으로 현대 이해

## 2. 핵심 기능

### 2.1 사건 관리 (Event)
```
카테고리: 군사, 외교, 정치, 경제, 사회
기능:
  ✓ 다단계 생성 폼 (기본정보 → 상세정보 → 위치 → 관계)
  ✓ 멘션 시스템 (@인물, #조직 자동 연결)
  ✓ 상하위 사건 계층 구조
  ✓ 타임라인 시각화
  
특화 기능 (군사):
  ✓ 교전국 관계 그래프 (양측 편, 동맹국 시각화)
  ✓ 병력/사상자 통계
  ✓ 지휘관 연결
```

### 2.2 인물 관리 (Person)
```
정보: 생몰년, 직업, 직위, 소속, 가족관계
연결: 참여 사건, 소속 조직, 국가
시각화: 타임라인, 관계도, 활동 내역
```

### 2.3 국가 & 지리
```
현대 국가: 정치/경제/인구 통계, 행정부 인사
역사적 국가: 왕조, 통치자, 영토 변천, 현대 국가 연결
지리: 대륙 → 국가 → 행정구역 → 도시 (계층 구조)
```

### 2.4 조직 & 군사
```
조직: 정부/정당/종교/기업 (구조, 구성원, 활동)
군사 조직: 부대 편제, 지휘관, 참전 기록
```

### 2.5 관리자 시스템
```
대시보드: 통계, 차트, 최근 활동
데이터 관리: CRUD, 필터, 검색, 가져오기/내보내기
사용자 관리: 계정, 권한, 활동 로그
```

### 2.6 사용자 포털
```
탐색: 사건/인물/국가 목록 및 상세
타임라인: 시간순 사건 배치, 필터링
검색: 통합 검색, 고급 필터
```

### 2.7 개발 도구
```
Electron 서비스 관리자:
  - 원클릭 시작/중지 (Docker, MySQL, API, Web)
  - 실시간 모니터링 (상태, 로그, 포트)
  - 빌드 도구 (API, SDK, DB 마이그레이션)
```

### 2.8 소셜 기능 (향후 계획) 🔮
```
사용자 기여:
  ✓ 사건/인물 추가/수정 제안
  ✓ 크라우드 소싱 (위키 방식)
  ✓ 검증 시스템 (투표/리뷰)
  
커뮤니티:
  ✓ 댓글/토론
  ✓ 큐레이션 생성 (맞춤 컬렉션)
  ✓ 팔로우/공유
  ✓ 기여도 포인트/뱃지
```

## 3. 기술 스택

### Backend
- **NestJS 11** (Node.js), **Prisma 7** (ORM), **MySQL 8**
- Clean Architecture + CQRS 패턴
- Nestia (자동 SDK 생성, Swagger)
- JWT 인증, Argon2 암호화

### Frontend
- **React 19**, **TypeScript 5.9**, **Vite 7**
- React Router 7, TanStack Query, Zustand
- styled-components + Tailwind CSS
- Feature-Sliced Design (FSD) 아키텍처

### DevOps
- **Nx** 모노레포, **Docker**, **Kubernetes**
- mise 환경 관리, Nginx, CI/CD 자동화

### 데이터베이스
- 22개 모듈화된 스키마 (도메인별 분리)
- 자동 마이그레이션, ERD 생성
- 계층적 관계 (사건↔인물↔조직↔국가)
