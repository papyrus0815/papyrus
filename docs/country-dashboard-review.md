## 0. 요약 — 근인 3축

이 지면은 **잘 만들어진 부품이 잘못된 모수 위에 놓여 있다.** 개별 패널(정권 슬라이더,
완성도 도넛, 대륙 비교, 피라미드)은 각자 완성도가 높은데, 첫 화면이 주는 인상은
"넓고 비어 있다"이다. 원인은 세 가지다.

**① 폭이 흡수되지 않는다.**
본문에 측정폭 상한이 없어 2,992px 화면에서 본문이 **2,202px**가 된다. 그 결과
`기록` 카드 한 장이 **710×178px**인데 담는 값은 `0` 한 글자, 정권 캐러셀 화살표는
카드에서 **1,600px 떨어진 곳**에 떠 있고, 히어로는 **2,202×168px**의 빈 띠다.
사건 목록에서 이미 겪고 `LIST_STEPS` 열 사다리로 해결한 것과 **같은 병**이다.

**② 화면의 모수가 실데이터와 어긋난다.**
대시보드는 "자료가 풍부한 나라"를 가정하고 6칸 격자 + 차트 2섹션을 **고정 배치**한다.
실제 DB는 그렇지 않다 — 조약 0행(전 국가), 군대 0행, 행정구역 2국, 선거 1국,
인구 피라미드 1국, 경제지표 0행, 사건 0건 43국(61%), 인물 0명 41국(58%).
그래서 대부분의 국가에서 첫 화면 절반이 **큼직한 `0`**이고, 페이지 끝은
"등록된 …이 없습니다" **2연발**로 끝난다.

**③ 시각 언어가 한 지면에 3벌이다.**
대시보드 자체 액센트 6색(indigo/violet/rose/amber/sky/emerald) + 피라미드 남녀
`#3b82f6`/`#ec4899` + 지표 차트 구글 팔레트(`#4285f4`/`#34a853`)와 **하드코딩 라이트
톤**(그리드 `#e5e7eb`, 흰 툴팁). 아이콘도 SVG 세트와 이모지(📈 👥)가 섞인다.

부수 축 하나 더: **국가 정체성 자산이 화면에 없다.** 썸네일 보유 2/71인데
`flag_emoji`는 **71/71** 다 있고, 히어로는 그걸 쓰지 않는다.

### 1-3. 진입 시 쿼리

대시보드 1회 진입에 **약 17개 요청**이 뜬다(stats 훅 11 + 정권 패널 4~5 + 지표 2).
이 중 **3쌍이 같은 엔드포인트를 다른 캐시 키로 두 번** 부른다.

| 데이터 | stats 훅 키 | 정권 패널 키 |

| 선거 | `['elections-by-country', id]` | `['elections','by-country',id]` |
| 부처 | `['administration-departments-by-country', id]` | `['administration-departments','by-country',id]` |
