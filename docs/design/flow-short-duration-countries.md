# 흐름도: 생존 기간이 짧은 국가 표기 검토

## 1. 현재 상황과 문제

- 흐름도 카드 너비는 **연도 구간 비율**로 계산: `widthPct = endPct - leftPct` (최소 0.5%).
- 연도 범위가 길수록(예: 300년) **1~5년짜리 국가**는 0.5%에 가깝게 되어, 픽셀 기준으로 매우 좁아짐.
- 예: 300년 범위 × 6px/년 = 1800px일 때 0.5% ≈ **9px** → 카드 내용(썸네일 40px + 텍스트)을 넣을 수 없고, 클릭·가독성 모두 나쁨.

즉, **짧은 기간 국가**는 연도 축에서는 올바른 위치에 두되, **표시 방식**을 다르게 가져가는 게 필요함.

---

## 2. 표기 옵션

### A. 툴팁 / 호버 확장

- **방식**: 카드는 그대로 좁게 두고, **호버 시** 툴팁 또는 인라인으로 국가명·기간·형태 표시.
- **장점**: 연도 축 정확도 유지, 겹침 없음, 구현 단순.
- **단점**: 호버 전에는 이름을 알기 어렵고, 터치 환경에서는 불리.

### B. 짧은 기간만 “필/마커” 형태

- **방식**: 기간이 **N년 미만**(예: 10년)이면 카드 대신 **짧은 세로 막대 + 국가명(또는 이니셜)** 필(pill) 또는 작은 마커로 표시. 클릭 시 상세 이동.
- **장점**: 연도 위치는 유지하면서, 짧은 구간만 컴팩트하게 표현 가능.
- **단점**: “카드”와 “필” 두 가지 UI를 유지해야 하고, N년 기준을 정해야 함.

### C. 최소 픽셀 너비 + 겹침 시 세로 오프셋

- **방식**: 카드에 **최소 너비(예: 80px)**를 두고, 그렇게 하면 다음 카드와 겹치면 **다음 카드를 한 줄 아래로** 살짝 내려서 겹치지 않게 배치.
- **장점**: 모든 국가가 카드 형태로 읽기 쉬움.
- **단점**: 레이아웃이 복잡해지고, “한 줄” 타임라인이 깨져 보일 수 있음.

### D. 짧은 기간 국가만 하단 “단기 국가” 목록으로 분리

- **방식**: 흐름도에는 **일정 기간 이상**(예: 10년)만 카드로 표시하고, **N년 미만**은 같은 연도 순으로 “단기 국가: A (1918–1920), B (1920–1921) …” 형태의 링크 목록을 막대 아래에 배치.
- **장점**: 타임라인은 깔끔하고, 짧은 국가도 빠짐없이 열람 가능.
- **단점**: 흐름도만 보면 “여기엔 뭐가 있었지?”를 한눈에 보기 어렵고, 두 영역을 오가야 함.

### E. 최소 너비만 픽셀 고정, 넘치면 말줄임 + 툴팁

- **방식**: 카드에 **min-width: 80px**(또는 72px)만 주고, **width는 여전히 연도 비율**. 따라서 짧은 국가는 80px로 보이지만 **오른쪽이 다음 카드와 겹칠 수 있음**. 겹치는 구간은 **z-index로 앞쪽 카드가 위에** 오게 하고, 짧은 카드는 내용을 **말줄임 + title(툴팁)**으로 기간/이름 표시.
- **장점**: “최소한 클릭 가능한 크기” 확보, 연도 위치는 대략 유지.
- **단점**: 겹침이 생기고, “정확히 겹치지 않게” 하려면 E와 B/C를 섞어야 함.

---

## 3. 권장 방향

- **1차 권장: B(필/마커) + A(툴팁)**  
  - 기간이 **예: 10년 미만**이면 **카드 대신** “연도 위치에 맞는 짧은 필(국가명 또는 약칭)”으로 표시.  
  - 필은 클릭 시 상세로 이동, **title** 또는 호버 툴팁으로 전체 이름·기간 표시.  
  - 10년 이상은 기존처럼 카드 유지.  
  - 연도 축 정확도 유지, 겹침 없음, 짧은 국가만 UI만 다르게 하면 되어 구현 부담이 상대적으로 적음.

- **2차 권장: A만 적용(툴팁/호버)**  
  - 우선 **모든 카드를 현재처럼 두고**, 너비가 일정 px 미만일 때만 **title** 또는 **호버 시 풀 내용** 표시.  
  - 구현이 가장 단순하고, “짧은 국가” 전용 컴포넌트 없이도 개선 가능.

- **구현 시 고려**
  - “짧은 기간” 정의: **연수 < 10** 또는 **widthPct < 2%** 등 한 가지 기준을 정해, 그때만 필/툴팁 적용.
  - 필 높이는 기존 카드와 비슷하게 두어 한 줄 안에서 시선이 자연스럽게 흐르도록 하는 것이 좋음.

---

## 4. 요약

| 옵션 | 연도 정확도 | 가독성 | 겹침 | 구현 난이도 |
|------|-------------|--------|------|-------------|
| A 툴팁 | 유지 | 호버 시만 | 없음 | 낮음 |
| B 필/마커 | 유지 | 좋음 | 없음 | 중간 |
| C 세로 오프셋 | 유지 | 좋음 | 없음(대신 2줄) | 높음 |
| D 하단 목록 | 유지 | 목록에서만 | 없음 | 중간 |
| E 최소 px + 겹침 | 약간 깨짐 | 보통 | 있음 | 중간 |

**정리**: 짧은 기간 국가는 **B(필) + A(툴팁)**로 “표기만 다르게” 두고, 연도 축은 그대로 두는 방식을 우선 검토하는 것이 무난함.
