# 역대 수반 직책명별 구분 설계

## 문제

현재 **역대 수반** 화면에서는 **쇼군·대통령·총리·국왕** 등 서로 다른 직책이 한 리스트에 섞여 있습니다.

- **쇼군**(군사권자) · **대통령**(공화국 국가원수) · **총리**(정부수반) · **국왕/황제**(군주)는 역할과 계보 의미가 다름.
- 한데 묶어서 “역대 수반” 하나로만 보여주면 혼란스럽고, 계보도(왕조 계보 vs 쇼군 계보 등)가 서로 다른 체계인데 섞여 보일 수 있음.

따라서 **직책(직책명) 단위로 구분**해서 보여주는 것이 맞습니다.

---

## 현재 데이터 구조

- **GovernmentPositionTenure**: 재임 1건 = 인물 + **직책** + 국가/역사적국가 + 기간 등.
- 직책 정보:
  - **positionDefinitionId** → `GovernmentPositionDefinition` (DB 관직 정의)
    - `title`: 직책명 (예: 대통령, 총리, 국왕, 쇼군)
    - `positionType`: `HEAD_OF_STATE` | `HEAD_OF_GOVERNMENT` | `REGENT` | …
  - **기타(직접 입력)** 인 경우: tenure의 **title** 필드에만 직책명 저장.

즉, “직책명”은 다음 둘 중 하나로 이미 존재합니다.

- 관직 정의 선택 시: `positionDefinition.title`
- 기타 직접 입력 시: `tenure.title`

---

## 제안: 직책명별 구분

### 원칙

- **표시 단위 = 직책(직책명)**  
  예: “국왕”, “쇼군”, “대통령”, “총리”를 각각 별도 그룹으로.
- **그룹 키**:  
  `positionDefinitionId`가 있으면 그 정의의 `title`, 없으면 `tenure.title`.  
  (둘 다 없으면 "기타" 등 하나의 그룹으로 묶기.)

### UI 제안

1. **목록 뷰**
   - 상단에 **직책별 섹션**으로 나누어 표시.
   - 예:
     - **국왕** (N명) — 해당 국가의 국왕 재임만.
     - **쇼군** (N명) — 쇼군 재임만.
     - **대통령** (N명), **총리** (N명) 등.
   - 각 섹션 내부는 기존처럼 재임 목록(대수/기간 등) 유지.

2. **계보 뷰**
   - **직책별로만** 계보 표시.
   - 예: “국왕 계보” 탭/선택 시 → 국왕 재임만으로 부모–자식 트리.
   - “쇼군 계보” 선택 시 → 쇼군 재임만으로 트리.
   - 국왕과 쇼군을 한 트리에 섞지 않음.

3. **수반 등록**
   - 기존처럼 “직책명”(관직 정의 또는 기타 직접 입력) 선택.
   - 등록 후 해당 직책 그룹에만 들어가도록, 그룹 키를 위 규칙(정의 title / tenure title)으로 일관되게 사용.

### 그룹 키 규칙 (구현용)

- `getPositionGroupKey(tenure)`:
  - `tenure.positionDefinitionId` 존재 → `positionDefinitions`에서 해당 정의의 `title` (또는 id로 매핑).
  - 없으면 `tenure.title` 또는 `tenure.position?.title`.
  - 둘 다 없으면 `"(기타)"`.
- 정렬:  
  그룹 표시 순서는 (1) 해당 국가에 실제로 존재하는 직책만 노출, (2) 그룹 간 순서는 직책명 정렬 또는 `positionType` 순서 등 정책에 따라 결정.

---

## 구현 포인트 (요약)

1. **heads-of-state-section.widget**
   - `tenures`를 `getPositionGroupKey(t)` 기준으로 그룹화.
   - 목록: 그룹별 섹션(제목 + 해당 그룹 재임 리스트) 렌더링.
   - 계보: 현재 선택된 “직책” 그룹의 tenures만으로 `lineageTenures` / `lineageRows` 등 계산 (또는 직책별 탭으로 직책 선택 후 같은 로직).
2. **API**
   - 재임 목록은 기존처럼 국가/역사적국가별 tenures 한 번에 조회해도 됨.  
   - 그룹화는 클라이언트에서 직책명(정의 title / tenure title) 기준으로 수행.
3. **계보**
   - `lineageTenures`를 “현재 선택된 직책 그룹”에 해당하는 tenures만 필터한 뒤, 기존 lineage 알고리즘 유지.

이렇게 하면 **쇼군·대통령·총리·왕을 직책명으로 구분**할 수 있고, 계보도 직책별로 분리해 보여줄 수 있습니다.
