# 역대 수반 계보도 위젯 — 문제점 정리

역대 수반 계보도(전체 보기) UI에서 현재 확인된 문제점을 정리한 문서입니다.

---

## 1. 공간 활용

### 1.1 가로 간격 과다

- **현상**: 직책 열(천황, 내각총리대신, 쇼군) 사이에 빈 공간이 과하게 넓게 보임.
- **원인 후보**:
  - 직책 간 스페이서 열을 두어 열 인덱스가 0, 2, 4처럼 떨어져 있고, 각 스페이서가 전체 열 너비(`COL_STEP`)를 차지함.
  - `COL_STEP`, `CARD_WIDTH`, `POSITION_GROUP_GAP_PX` 등 상수가 커서 열·카드 간격이 넓음.
- **개선 방향**: 스페이서 열 제거 후 직책 열을 연속 배치(0, 1, 2, …)하고, 구분은 구분선 + 첫 카드 `margin-left`(POSITION_GROUP_GAP_PX)만 사용. 필요 시 상수 추가 축소.

### 1.2 세로 빈 공간

- **현상**: 타임라인 상·중간에 카드가 거의 없고, 1400년대~1800년대 구간이 크게 비어 보임.
- **원인**: 데이터 자체가 해당 기간에 소수만 있음(예: 쇼군 1명, 천황·총리 각 1명). 연도 기준 배치라 카드가 실제 재임 연도 위치에만 배치됨.
- **개선 방향**: 데이터 밀도가 낮을 때도 보기 좋게 하려면 (1) 타임라인 높이 상한 유지로 스크롤 길이 제어, (2) 필요 시 “해당 기간 데이터 없음” 등 안내 문구, (3) 줌/축소 옵션 검토.

### 1.3 특정 직책 열 비어 보임

- **현상**: “내각총리대신” 열은 카드가 한두 개뿐이라 열 대부분이 비어 보임.
- **원인**: 해당 국가·기간에 내각총리대신 데이터가 적음. 데이터가 있는 직책만 열로 쓰는 로직을 써도, 한 직책에 카드가 1개면 열이 넓게 비어 보임.
- **개선 방향**: 열 너비를 카드 개수에 비례해 줄이거나, 카드가 적은 직책은 최소 열 너비만 쓰도록 레이아웃 조정 검토.

## 2. 타임라인

### 2.1 라벨 단위만 100년

- **현상**: 타임라인에는 1400년, 1500년, … 처럼 100년 단위 라벨만 있어, 구체적인 재임 시작·종료 시점을 읽기 어려움.
- **개선 방향**: (선택) 50년 단위 보조 눈금, 또는 카드에 마우스 오버 시 정확한 연도 툴팁 등으로 보완 검토.

### 2.2 막대만 있고 구간 구분 없음

- **현상**: 타임라인 좌측의 세로 막대는 1400년~1900년을 한 덩어리로만 표시하고, 개별 재임 구간이 막대 위에 구분되어 보이지 않음.
- **개선 방향**: (선택) 재임 구간별 색/두께 차이, 또는 막대 위에 짧은 마커로 구간 표시 등 검토.

### 2.3 minYear 반영 및 첫 라벨

- **이슈**: 데이터 최소 연도(minYear)가 1449년인데, 타임라인이 1500년부터만 보이면 “1449년 카드가 1500년보다 위에 있다”는 것이 직관적이지 않을 수 있음.
- **개선 방향**: minYear를 포함하는 세기부터 라벨 표시(예: 1449년이면 1400년 라벨 포함). 이미 반영했는지 코드에서 확인 필요.

## 3. 카드

### 3.1 카드 내용 세로 정렬

- **현상**: 카드 내 텍스트(직책 뱃지, 이름, 재위 기간 등)가 위쪽으로 치우쳐 보일 수 있음.
- **개선 방향**: 카드 본문을 한 덩어리(`TreeCardContent`)로 묶고, `TreeCard`에 `justify-content: center`로 세로 중앙 정렬. 아바타는 `position: absolute`로 유지해 본문만 중앙 정렬.

### 3.2 가변 카드 높이

- **목표**: 재임 기간에 비례해 카드 높이를 다르게 해, 4년 재임과 44년 재임이 시각적으로 구분되게 함.
- **현상**: 최소 높이만 쓰면 짧은 재임·긴 재임이 비슷해 보일 수 있음.
- **개선 방향**: 연도 기준 레이아웃에서 카드 높이를 “재임 연수 × PX_PER_YEAR”로 계산하고, 최소/최대 높이(min/max)로 클램핑해 짧은 재임은 낮게, 긴 재임은 높게 표시.

### 3.3 카드끼리 겹침/배치 이상

- **현상**: 서로 다른 직책 카드(예: 메이지, 이토 히로부미)가 연도 기준으로 비슷한 시기에 있으면, 세로로 겹치거나 살짝 어긋나 보일 수 있음.
- **원인**: 연도 기준 배치에서 `top`이 재임 시작 연도로만 결정되고, 같은 열 내에서만 겹침을 피하는 로직이 없을 수 있음.
- **개선 방향**: 같은 열에서 기간이 겹치는 카드가 있으면 `top`을 미세 조정해 겹치지 않게 하거나, “의도된 겹침”으로 두고 z-index로 클릭만 정상 동작하도록 유지.

---

## 4. 직책 헤더·구분선

### 4.1 헤더와 카드 열 정렬

- **확인 사항**: 직책 헤더의 `left`/`width`가 실제 카드 열(`startCol`, `colCount`, `COL_STEP`, `POSITION_GROUP_GAP_PX`)과 일치하는지.
- **개선 방향**: 스페이서 제거 후 헤더도 연속 열 기준으로 계산해, 첫 카드에만 GAP을 주는 방식과 동일하게 맞춤.

### 4.2 구분선과 카드 간격

- **이슈**: 직책 구간 구분선과 해당 열 첫 카드 우측이 너무 붙어 있거나, 반대로 간격이 과하게 넓을 수 있음.
- **개선 방향**: `POSITION_GROUP_GAP_PX`로 구분선 오른쪽 ~ 첫 카드 왼쪽 간격을 일관되게 적용하고, 필요 시 상수만 조정.

---

## 5. 데이터·표시 일관성

### 5.1 재위/대수 번호

- **목표**: 수정 폼에서 재위/대수를 비우고 저장하면 DB에서 제거(null)되도록 함.
- **확인**: API에서 `termNumber`/`regnalNumber`를 `null`로 받아 필드 제거하는지 확인.

### 5.2 인물 선택 후 이름 표시

- **목표**: 모달에서 고른 인물이 `persons`에 없어도 `allPersonsForModal`에서 찾아 이름 표시.
- **확인**: `selectedPerson = persons.find(...) ?? allPersonsForModal.find(...) ?? null` 로직 적용 여부.

### 5.3 직함 없을 때 하이픈

- **목표**: 직함이 없을 때만 나오던 “—” 제거, 의미 있을 때만 직함 표시.
- **확인**: `titleText`가 없거나 `'—'`일 때 `TreeCardTitle`을 렌더하지 않는지.

---

## 6. 이미 해결된 항목 (참고)

- 연결선 제거: 전체·직책 선택 모두에서 부모–자식 연결선 미표시.
- 직책 헤더: 전체 보기에서만 직책명/뱃지 표시, 특정 직책 선택 시 숨김.
- 연도 기준 배치: 전체 보기에서 막대·카드 위치를 `yearRange`(minYear~maxYear) 기반으로 계산.
- 연도 기준 높이 상한: `MAX_YEAR_BASED_HEIGHT`로 전체 높이 상한 두어 스크롤 과다 방지.
- 세기 라벨 클램핑: 타임라인 세기 구간 top/height를 [0, totalH] 안으로 클램핑해 라벨이 영역 밖으로 나가지 않도록 함.
