# 역사적 국가 관계 구조 검토

## 현재 구현 요약

| 개념 | 저장 위치 | 의미 | 입력 경로 |
|------|------------|------|-----------|
| **상위 현대 국가** | `HistoricalCountryModernCountry` | 이 역사적 국가가 연결되는 현대 국가(들) | 역사적 국가 등록/수정 폼 |
| **상위 역사적 국가** | `HistoricalCountryMembership` + `HistoricalCountryTransition` | 실제 의미: **후임 국가** (고려 → 조선) | 역사적 국가 등록/수정 폼 |
| **소속·구성** | `HistoricalCountryMembership` | 상위–하위 구조 (신성로마제국–제후국), 역할 있음 | 역사적 국가 상세 → 소속·구성 탭 |
| **국가 관계** | `HistoricalCountryRelation` | 수평 관계 (조공·동맹·전쟁 등) | 역사적 국가 상세 → 국가 관계 탭 |

---

## 적절한 부분

1. **상위 현대 국가**  
   - 역사적 국가 ↔ 현대 국가 연결은 별도 테이블(`HistoricalCountryModernCountry`)로 명확함.  
   - “이 과거 국가가 어떤 오늘날 국가와 이어지는가”를 표현하기에 적절함.

2. **국가 관계 (Relation)**  
   - 주체–대상 + 관계 유형(조공·동맹·전쟁 등)으로 수평 관계만 담당.  
   - 한·중 조공, 동맹 등 용도에 맞음.

3. **소속·구성 (Membership) 탭**  
   - 상위(historicalCountryId)–하위(memberCountryId) + 역할(속국·연방 구성원 등)으로 구조적 소속을 표현.  
   - 신성로마제국–제후국 같은 관계에 적합함.

---

## 문제점

### 1. “상위 역사적 국가”와 Membership 중복

- **폼의 “상위 역사적 국가”**는 실제로 **후임 국가(successor)**만 의미함 (고려가 조선을 “상위”로 선택 = 조선이 후임).
- 그런데 이때 **두 군데**에 동시에 저장됨:
  - `HistoricalCountryTransition`: 전임(고려) → 후임(조선), 변천 유형  
  - `HistoricalCountryMembership`: parent=조선, member=고려, role=OTHER  

**문제:**

- **계승/변천**은 `Transition`만으로 이미 완전히 표현 가능함.
- 같은 관계를 `Membership`에 또 넣으면:
  - “고려 is a member of 조선”이라는 문장이 되는데, 계승 관계를 “소속”으로 해석하는 것은 자연스럽지 않음.
  - **소속·구성 탭**의 Membership(신성로마–제후국 등)과 **의미가 다름**에도 같은 테이블을 쓰게 됨.
- 따라서 **후임 국가 설정 시 Membership 생성은 중복**이며, 의미적으로도 혼란을 줄 수 있음.

### 2. 용어 혼란

- UI/도메인에서 **“상위 역사적 국가”**라고 하면, 사용자는 보통 “나를 포함하는 상위 국가”를 떠올리기 쉬움.
- 실제로는 **“후임 국가(이어져 간 국가)”**를 넣는 필드라, **“상위”와 “후임”이 혼용**되고 있음.

---

## 권장 방향

### A. 후임 국가 설정 시 Membership 생성 제거 (권장)

- **“상위 역사적 국가”(후임) 저장 시**  
  - `HistoricalCountryTransition`만 생성/수정하고,  
  - `HistoricalCountryMembership`는 **생성/수정하지 않음**.
- **Membership**은 **소속·구성 탭**에서만 사용:
  - 신성로마제국–제후국, 연방–구성원 등 **구조적 상위–하위**만 저장.
- 효과:
  - 계승/변천 = Transition  
  - 구조적 소속 = Membership  
  으로 역할이 분리되어, 모델과 UI가 일치함.

### B. UI 라벨 정리

- 폼 필드명을 **“상위 역사적 국가”** 대신  
  **“후임 국가”** 또는 **“이어져 간 국가”**로 바꾸면,  
  “고려가 조선을 선택 = 조선이 후임”이라는 의미가 명확해짐.

### C. (선택) 상위 현대 국가 라벨

- “상위 현대 국가”는 “연결된 현대 국가” 또는 “관련 현대 국가”로 바꿀 수 있음.  
  “상위”가 역사적 국가 간 관계에만 쓰이도록 하면 일관성이 좋아짐.

## 요약

| 항목 | 판단 | 비고 |
|------|------|------|
| 상위 현대 국가 | ✅ 적절 | 별도 테이블, 역할 명확 |
| 상위 역사적 국가(후임) | ⚠️ 개선 필요 | Transition만 쓰고, Membership 생성 중단 권장 |
| 소속·구성 (Membership) | ✅ 적절 | 구조적 상위–하위 전용으로 사용하는 것이 좋음 |
| 국가 관계 (Relation) | ✅ 적절 | 수평 관계 전용으로 적합 |

**핵심 권장:**  
“상위 역사적 국가(후임)” 저장 시 **Transition만** 다루고, **Membership 생성/수정은 하지 않는 것**이 적절한 방법에 가깝습니다.
