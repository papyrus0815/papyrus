# 한 국가 내 복수 직책(로마왕·이탈리아왕·황제) 설정 방법

## 질문

신성로마제국처럼 **로마왕**, **이탈리아왕**, **신성로마황제** 같은 직책을 어떻게 설정할까?

## 현재 구조 요약

- **역사적 국가** / **현대 국가**: 각각 하나의 엔티티(신성로마제국, 이탈리아 등).
- **역대 수반(재임)**: `GovernmentPositionTenure` = **한 사람 + 한 직책 + 한 국가(또는 역사적국가) + 기간**.
- **직책**: `GovernmentPositionDefinition`에 직함(국왕, 황제, 쇼군 등)이 전역으로 정의되며, 재임 등록 시 그중 하나를 선택하거나 **기타(직접 입력)**으로 직책명을 넣을 수 있음.

## 결론: **재임을 여러 개 등록하면 됨**

한 사람이 **같은 역사적 국가·같은 기간**에 여러 직책을 겸한 경우, **재임(tenure)을 직책마다 하나씩** 등록하면 됩니다.

| 인물   | 직책           | 소속(역사적 국가) | 기간     |
|--------|----------------|--------------------|----------|
| 오토 1세 | 로마왕         | 신성로마제국       | 936–973  |
| 오토 1세 | 이탈리아왕     | 신성로마제국       | 951–973  |
| 오토 1세 | 신성로마황제   | 신성로마제국       | 962–973  |

- **국가**는 **신성로마제국** 하나만 사용(역사적 국가로 등록).
- **로마왕**, **이탈리아왕**, **신성로마황제**는 서로 다른 **직책**이므로, 위처럼 재임 3건을 넣으면 됨.

## 설정 방법

### 1) 관직 정의에 직책 추가 (권장)

관직 정의 시드에 다음이 포함되어 있음(또는 국가 상세 → 관직 정의에서 동일하게 추가 가능):

- **로마왕** (King of the Romans, Rex Romanorum)
- **이탈리아왕** (King of Italy, Rex Italiae)
- **신성로마황제** (Holy Roman Emperor, Imperator Romanorum)

역대 수반 등록 시 직책 선택 목록에서 위 항목을 고르면 됨.

### 2) 기타(직접 입력)

목록에 없는 직책은 **기타(직접 입력)**을 선택한 뒤, 직책명에 "로마왕", "이탈리아왕" 등을 입력해도 됨.

### 3) 역대 수반 화면에서의 표시

- 역대 수반은 **직책명별로 구분**되어 표시됨(로마왕 / 이탈리아왕 / 신성로마황제 섹션·탭).
- 계보도도 직책별로 선택해 볼 수 있음.

## 정리

| 항목     | 설정 방법 |
|----------|------------|
| 국가     | **신성로마제국** 하나를 역사적 국가로 등록하고, 모든 재임의 소속을 이걸로 통일 |
| 로마왕   | 직책 "로마왕"으로 재임 1건 등록 (해당 기간) |
| 이탈리아왕 | 직책 "이탈리아왕"으로 재임 1건 등록 (해당 기간) |
| 신성로마황제 | 직책 "신성로마황제"로 재임 1건 등록 (대관일~종료) |

**한 polity(신성로마제국) 안에서 여러 직함을 쓰는 경우 = 같은 국가·같은 사람·같은(또는 겹치는) 기간에 재임을 직책마다 여러 개 두는 것**으로 표현하면 되고, 현재 데이터 모델과 UI로 모두 가능합니다.

## 신성로마제국 ↔ 현대 국가(독일 등) 연결

### "지칭"을 독일로 바꿀 필요는 없음

- **역사적 국가 이름**은 그대로 **「신성로마제국」**으로 두면 됩니다.
- 현대 국가 이름(독일)으로 **이름을 바꿀 필요는 없고**, "이 역사적 국가가 **어느 현대 국가와 연결되는지**"만 설정하면 됩니다.

### 현대 국가 연결이란

- 테이블 **`HistoricalCountryModernCountry`** (또는 API의 **`parentModernCountryIds`**)로  
  **역사적 국가 ↔ 현대 국가**를 N:N 연결합니다.
- **신성로마제국**에 **독일**을 연결해 두면:
  - **독일** 연대표/국가 상세에서 "이 현대 국가와 연결된 역사적 국가"로 **신성로마제국**이 노출되고,
  - "독일 → 신성로마제국" 흐름으로 역대 수반·사건을 볼 수 있습니다.

### 어떻게 설정하면 되나

1. **역사적 국가** 신성로마제국을 등록/수정할 때  
   **연결할 현대 국가**에 **독일**을 선택(또는 `parentModernCountryIds`에 독일 ID 포함).
2. 그러면 **이름은 "신성로마제국"** 그대로 두고, **지칭/표시는 독일과 연관**되게 할 수 있습니다.
3. 영토/계승이 복잡하면 **오스트리아·스위스·체코·이탈리아** 등 여러 현대 국가와도 연결 가능합니다(N:N).

### 요약

| 항목 | 권장 |
|------|------|
| 역사적 국가 **이름** | **신성로마제국** 유지 (독일로 바꾸지 않음) |
| 현대 국가 **연결** | **독일**을 연결(주 계승국). 필요 시 오스트리아 등 추가 |
| 용도 | 독일 페이지에서 신성로마제국을 전신으로 보기, 연대표에서 독일 선택 시 신성로마제국 포함 |

## 프랑크 왕국과 서·중·동 프랑크 (자세한 연결 구조)

### 연결의 두 가지 종류

이 시스템에서는 **역사적 국가**가 다음 두 방식으로만 연결됩니다.

| 종류 | 테이블/API 필드 | 의미 | 관계 |
|------|------------------|------|------|
| **역사적 ↔ 역사적** | `HistoricalCountryTransition` / `parentHistoricalCountryIds` | "전임 국가 → 후임 국가" (계승·분열·통일 등) | **전임(predecessor)** 하나당 **후임(successor)** 여러 개 가능 (전임이 쪼개지면 후임 여러 개) |
| **역사적 ↔ 현대** | `HistoricalCountryModernCountry` / `parentModernCountryIds` | "이 역사적 국가는 오늘날 어느 현대 국가와 연결해 보여줄지" | **N:N** (한 역사적 국가 ↔ 여러 현대 국가, 한 현대 국가 ↔ 여러 역사적 국가) |

- **역사적 국가 이름**은 바꾸지 않고, 위 두 연결만 설정하면 됩니다.
- API/UI에서 **"상위 역사적 국가"** = **후임**입니다. 즉, "이 국가(전임)가 **이어져서** 어떤 국가(후임)가 되었는지"를 넣는 곳입니다.

---

### 1. 역사적 국가 4개 등록

| 역사적 국가 | 영문명 예시 | 존속 기간 (참고) | 비고 |
|-------------|-------------|------------------|------|
| **프랑크 왕국** | Francia / Frankish Kingdom | 481 또는 751 ~ 843 | 통일 프랑크. 843 베르됭 조약으로 분열 |
| **서프랑크** | West Francia | 843 ~ 987 | → 카페 왕조·프랑스 왕국 |
| **중프랑크** | Middle Francia / Lotharingia | 843 ~ 855(로타르 1세 사후 재분할) | 로트링겐 등, 이후 프랑스·독일·이탈리아·저지대에 흡수 |
| **동프랑크** | East Francia | 843 ~ 962 | 오토 1세 대관 → 신성로마제국으로 이어짐 |

- 각각 **역사적 국가(HistoricalCountry)** 한 건씩 등록합니다. 이름·영문명·존속 기간만 넣고, **연결은 아직 하지 않아도** 됩니다.

---

### 2. 프랑크 왕국 — 어떻게 연결되는지

**프랑크 왕국**은 분열한 쪽이므로 **전임(predecessor)** 이고, 서·중·동 프랑크가 **후임(successor)** 입니다. **HistoricalCountryTransition**에는 전임 → 후임 관계를 넣습니다.

#### 2-1. 역사적 국가와의 연결 (계승)

- **설정 위치**: **프랑크 왕국**을 수정할 때, **상위(후임) 역사적 국가**에 **서프랑크, 중프랑크, 동프랑크** ID를 넣고, **계승 이벤트**에 `TREATY` 또는 `SPLIT`를 선택합니다.
- **DB**: 위처럼 넣으면 `HistoricalCountryTransition`에 전임=프랑크 왕국, 후임=서/중/동 각 1행씩 총 3행이 생성됩니다.

| 전임 국가 (predecessor) | 후임 국가 (successor) | eventType |
|-------------------------|------------------------|-----------|
| 프랑크 왕국 | 서프랑크 | TREATY 또는 SPLIT |
| 프랑크 왕국 | 중프랑크 | TREATY 또는 SPLIT |
| 프랑크 왕국 | 동프랑크 | TREATY 또는 SPLIT |

이렇게 하면 “프랑크 왕국 → 서/중/동 프랑크” 계보가 연대표·국가 계승 뷰에서 표현됩니다.

#### 2-2. 프랑크 왕국 ↔ 현대 국가

프랑크 왕국 수정 시 **연결할 현대 국가**에 **프랑스, 독일** 선택 → `HistoricalCountryModernCountry`에 (프랑크 왕국, 프랑스), (프랑크 왕국, 독일) 생성. 프랑스·독일 연대표에서 프랑크 왕국이 전신으로 보임.

---

### 3. 서프랑크 — 연결

- **역사적**: 전임=프랑크 왕국(이미 지정). 후임(선택)=프랑스 왕국 등.
- **현대**: 서프랑크 수정 시 연결할 현대 국가 = **프랑스**. (서프랑크, 프랑스) 한 행.

### 4. 중프랑크 — 연결

- **역사적**: 전임=프랑크 왕국. 후임(선택)=로트링겐·이탈리아 왕국 등.
- **현대**: 연결할 현대 국가 = **프랑스, 독일, 이탈리아, 네덜란드, 벨기에** 등 복수. N:N.

### 5. 동프랑크 — 연결

- **역사적**: 전임=프랑크 왕국. 후임(선택)=**신성로마제국** (동프랑크 수정 시 상위 역사적 국가에 신성로마제국 ID).
- **현대**: 연결할 현대 국가 = **독일**. (동프랑크, 독일) 등.

### 6. 전체 요약표

| 역사적 국가 | 전임(역사적) | 후임(역사적) | 현대 국가 연결 |
|-------------|--------------|--------------|----------------|
| 프랑크 왕국 | 없음 | 서프랑크, 중프랑크, 동프랑크 | 프랑스, 독일 |
| 서프랑크 | 프랑크 왕국 | (선택) 프랑스 왕국 | 프랑스 |
| 중프랑크 | 프랑크 왕국 | (선택) 로트링겐 등 | 프랑스, 독일, 이탈리아 등 |
| 동프랑크 | 프랑크 왕국 | (선택) 신성로마제국 | 독일 |

### 7. 설정 순서

1. 역사적 국가 4개 생성(이름·기간만).
2. **프랑크 왕국** 수정: 상위(후임) 역사적 국가 = 서프랑크, 중프랑크, 동프랑크 / 계승 이벤트 = TREATY 또는 SPLIT / 연결할 현대 국가 = 프랑스, 독일.
3. **서프랑크** 수정: 연결할 현대 국가 = 프랑스. (선택) 상위 역사적 국가 = 프랑스 왕국.
4. **중프랑크** 수정: 연결할 현대 국가 = 프랑스, 독일, 이탈리아 등 복수.
5. **동프랑크** 수정: 연결할 현대 국가 = 독일. (선택) 상위 역사적 국가 = 신성로마제국.

### 8. 역대 수반(재임)은 국가별로

- **프랑크 왕국** 역대 왕 → 소속 역사적 국가 = **프랑크 왕국**, 직책 = 국왕(또는 황제, 시기별로 선택).
- **서프랑크** / **중프랑크** / **동프랑크** 왕 → 각각 해당 **역사적 국가**를 소속으로 두고 재임을 등록하면 됩니다.
- 한 사람이 여러 프랑크를 겸한 경우(예: 로타르 1세가 중프랑크+이탈리아 등)는, **겸한 국가마다 재임을 따로** 넣으면 됩니다(신성로마제국 로마왕/이탈리아왕/황제와 같은 방식).
