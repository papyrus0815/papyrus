# 사건 상세 개선 검토 (2026-11-05)

표본 7건 × 탭 전부 × 데스크톱 1500px / 모바일 390px 실측(headless Chrome, 쓰기 요청 차단).
표본: 프랑스 혁명(묶음·국면 없음·하위 4/전체 75) · 입법의회기(국면 3) · 발미 전투(단일·좌표) · 1차세계대전(묶음 18) ·
샌프란시스코 강화조약(참여 29) · 일본 최초 철도(긴 글) · 글 없는 사건(주코프-티모셴코 선제 타격 계획).

기본 건강: 콘솔 오류 0 · 가로 넘침 0(전 탭·두 폭) · API 15~19건/상세, 가장 느린 응답 150ms(`/events?limit=all`).

## 근인 2개

1. **히어로가 '요약 카드'가 아니라 '전부 보여 주기'다.** 이미지·제목·날짜·인물 줄·참여국 카드·위치·원어명·당시 수장이
   전부 탭 위에 쌓여, 본문(탭)이 첫 화면 밖으로 밀린다. 모바일 전용 처리(@media)가 hero에 하나도 없다.
2. **같은 사실을 세 지면이 각자 말한다.** 날짜(제목·히어로·우측 칸 큰 연도), 참여국(히어로 카드·우측 사실표·참여 탭),
   '채우기'(본문 안내·우측 '비어 있는 항목'·'더 채울 수 있는 것'), 하위 목록(전개·우측 목차).

## P1 — 첫 화면

| # | 무엇 | 실측 | 방향 |
|---|---|---|---|
| 1 | 모바일 본문이 첫 화면 밖 | 탭 시작 y = 515~811px / 화면 844px (발미 765, 철도 811) | 모바일: 이미지 높이 상한(≈96px), 참여국 카드 → 한 줄 칩(`독일 제국 외 3 · 미국 외 10`), 위치·원어명·당시 수장은 '사실 N개 보기' 안으로 |
| 2 | 모바일 머리 버튼 겹침 | `⋯`가 빵부스러기에 밀려 혼자 한 줄(철도) · 우상단 아바타 FAB가 `?` 덮음 · 좌하단 메뉴 FAB가 본문 첫 줄 덮음 | 빵부스러기 1줄 말줄임 + 액션은 같은 줄 우측 고정, 상세 지면에서는 FAB에 하단 여백(safe padding) |
| 3 | 데스크톱 묶음 사건도 탭이 늦음 | 1차대전 탭 y = 763 / 950 (그림 207px + 진영 카드 250px) | 이미지 있는 묶음은 이미지 높이 상한, 진영 카드 진영당 2개 + '+N' (지금 3개) |
| 4 | 모바일 탭 줄이 잘려도 신호 없음 | 1차대전 '연…'에서 잘림, 스크롤 가능 표시 없음 | 우측 페이드 + 활성 탭 scrollIntoView |

## 미확인

- 다크 모드: 헤드리스에서 테마 전환이 안 먹어 미확인.
- 참여 탭 내부(샌프란시스코 버튼 131개)·연관 탭 세부·조망 간트는 첫 화면만 봄.

## 배치 제안

1. **첫 화면(P1 1~4)** — hero 모바일 분기 + 묶음 이미지 상한 + 탭 줄 페이드. 백엔드 0.
2. **중복 정리(P2 5~8, 11)** — 우측 사실표·목차 규칙. 백엔드 0.
3. **진영 자리표시·빈 탭(9, 10)** — 표시 규칙 + 진입점.
4. **P3 묶음.**
