## 🔶 2차 후보 (검증 통과, 미구현) — 원하시면 진행

### 정보/밀도
- **연도 → 월·일(precision 게이트)** [EL-2/C4/RAIL-3, P2]: 연 그룹 내 행의 연도 중복을 `startDatePrecision==='day'`면 `M.D`, `'month'`면 `M월`, 그 외 숨김으로 대체. ⚠️ 연도만 아는 이벤트가 `01-01`로 저장된 경우 오도 위험 → precision 게이트 필수(med risk).
- **행 세로 padding 미세 축소** [L5, P3]: `10px→8px`로 ~44→~38px 더 촘촘히.

### 레일/구조 (정거장 메타포 유지하며 정제)
- **세기+연도 이중 sticky blur 단일화** [RAIL-2, P3]: 연 헤더 `backdrop-filter` 제거→불투명 solid로 강등(세기만 glass). blur 스택 비용·시각 소음↓.
- **접힌 연도 밴드 축소** [RAIL-4, P2]: `CollapsedPlaceholder` 패딩/폰트 축소(~40→~24px)로 '압축 구간' 인상 강화.
- **레일 척추 alpha 상향** [RAIL-5, P3]: 세로선(0.16/0.14)이 커넥터(0.35/0.45)보다 옅은 역전 해소.
- **세기 직후 첫 연도 divider border-top 제거** [RAIL-6, P3]: 시대 경계 이중 hairline 정리.
- **세기 카운트 메타 컬럼 정렬** [L4, P3]: 세기 divider 카운트를 행 메타(880px)에 맞춰 우측 가장자리 일치.

### 크로스뷰 일관성
- **카테고리 hue 정본 통일** [X2, P2]: `theme.ts` 내부 military가 뷰마다 다른 hue → 단일 토큰으로. 목록↔타임라인 색 점프 제거.
- **중요도 표현 수렴** [X1, P3]: 목록=별 / 그리드·트리=`ImportancePill` 칩 / 타임라인=막대. 공용 `ImportancePill muted` 변형으로 통일 검토(취향 갈림 — 보류 성향).

### 빈/로딩/상태
- **스켈레톤 단일행 동기화** [L3, P2]: 실제 행이 1단이 됐으므로 스켈레톤도 1단으로(로딩→데이터 점프 방지). *1차 구현의 짝 — 우선순위 높음.*
- **스켈레톤에 세기/연도 divider placeholder** [RS7, P3]: 데이터 도착 시 divider 삽입 점프 방지.
- **빈 상태 아이콘 3-way** [RS3, P3]: 등록0=`FiInbox`·필터0=`FiFilter`·검색0=`FiSearch` (현재 항상 깔때기 → 오해).
- **'연도 미상' divider hollow 도트** [RS4, P2]: 확정 연도와 시각 무게 동일 → 불확실 신호(빈 도트)로 구별.
- **부분 로드 실패 행 경고 아이콘** [RS6, P3]: `FiAlertCircle` 추가로 오류 즉시 식별.
- **EmptyCatalogState 모바일 마진 축소** [RS5, P3].

### 색 토큰 정리
- **인디고 리터럴 → BRAND.\* 토큰** [C3, P3]: `#2563eb`·`rgba(37,99,235,*)` 난립을 토큰 경유로(유지보수).
