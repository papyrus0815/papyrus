## 1. 입력이 막히는 것 — P1

### O1. 소련 쪽 부대를 넣을 방법이 없다
- 소련 측 '부대 투입'에 뜨는 선택지는 **'제1군 (야전군 · 독일 제국)' 하나**(1차대전 독일군).
  - 선택지는 전 세계 부대를 진영 소속국 순으로 *정렬*만 한다 — 남의 나라 부대를 투입할 수 있다.
- '새 부대 등록하기' 링크는 **선택지가 0일 때만** 보이고, 다른 지면으로 간다.
- **제안:**
  - 선택지는 진영 소속국(역사·현대) 부대만, '다른 나라 부대도 보기' 토글.
  - '＋ 새 부대 만들어 투입' 한 줄: 이름 · 종류(전선군·군·군단·사단…) · 소속 = 기관(스타프카·총참모부 / OKH) 또는 상위 부대(이 진영에 이미 투입된 부대).
  - 만들면 바로 투입.

### O2. 병기·장비 카탈로그가 0건
- 병기·지상차량·항공기·함선 마스터가 전부 0행이다. 고르기만 있어서 투입 병기 기능을 쓸 수 없다.
- **제안:**
  - O1과 같은 인라인 생성(이름 · 분류 · 국가).
  - 독소전 주요 장비 기본 시드: Ⅲ·Ⅳ호 전차, T-34, KV-1, BT-7, T-26, Bf 109, Ju 87, Il-2, MiG-3 등 20종 안팎.

### O3. 부대별 병력을 부대 카드에서 적을 수 없다
- 지금 경로: 수치 섹션 → '수치 추가' → 대상 목록에서 '⚔️ 진영 · 부대' 찾기.
- **제안:** 부대 카드에 '병력·전차 적기' 버튼 — 대상을 미리 고른 수치 창. 병력·전차·항공기·화포는 추천 지표로 맨 위에.

## 2. 흐름이 안 남는 것 — P2

### O4. 부대가 4년짜리 묶음에만 붙어 있다
- 중부집단군·제2기갑집단이 '동부전선 (1941–45)'에 붙어 있고, 하위 24건에는 0건이다.
- 시기별 편성(1941 중부집단군 vs 1944 바그라티온의 같은 집단군)이 남지 않는다.
- **제안:**
  - 하위 사건 진영에 **'상위 사건 전투서열에서 고르기'**(상위에 투입된 부대를 체크로 한 번에).
  - 묶음 자체에 넣은 부대는 '전 기간 편성'으로 표시.
  - 하위에서 올라온 부대는 이미 있는 '하위 사건 참전 진영·부대·지휘관 모아보기'가 모은다.

### O5. 하위 사건 진영을 매번 새로 만든다 — 이름·나라가 어긋난다
- 하위 사건 진영 10개 중 **상위 진영을 이어받은 것 0개**.
- 어긋난 이름:
  - '진영 1 / 진영 2'(이름 미입력)
  - '러시아 소비에트 연방 사회주의 공화국 측'(러시아 SFSR)과 '소비에트 사회주의 공화국 연방 측'(소련)이 섞임
  - 이탈리아 대소 선전포고의 '루마니아 왕국 측'
- 조망의 진영별 집계·색이 사건마다 따로 논다.
- **제안:**
  - 하위 사건에서 '진영 추가'를 누르면 **상위 진영 그대로 쓰기**가 기본 — parentSideId 연결, 이름·색 상속.
  - 새로 만드는 것은 보조.
  - 기존 10개는 상위 진영에 잇는 일괄 정리 버튼.

### O6. 부대가 글 속에만 있다
- 메모 "제24·46·47기갑군단", 제목 "구데리안 제2기갑집단(제18기갑사단)의 부크강 수중도하"에 부대가 글로만 있다.
- **제안(P3):** 제목·메모에서 이미 있는 부대 이름을 찾아 '이 부대를 투입할까요?' 칩. 없는 이름은 '부대로 만들기'.

## 3. 보기 — P2

### O7. 전투서열이 진영 카드(폭 약 270px) 안에 있다
- 지금은 2단(집단군 › 기갑집단)인데도 메모가 4줄로 접힌다.
- 군단·사단까지 내려가면 4단 들여쓰기로 이름이 잘린다.
- **제안:**
  - 진영 카드 아래 전체 폭 '전투서열' 판: 두 진영 나란히, 계층 표.
  - 열: 부대 · 몫 · 지휘관 · 병력 · 전차.
  - 진영 카드에는 '부대 N개 · 병력 합 N' 요약만.

## 4. 순서 제안
1. **O1 + O2** — 부대·병기 인라인 생성(+ 장비 기본 시드). 이게 없으면 소련 쪽과 병기를 아예 못 넣는다.
2. **O5** — 상위 진영 이어받기. 지금 하위 사건이 계속 늘고 있어 빨리 할수록 정리할 게 적다.
3. **O3** — 부대 카드의 병력 적기.
4. **O4** — 상위 전투서열에서 고르기.
5. **O7**, 그다음 **O6**.
