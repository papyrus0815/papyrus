# 최상위 사건 조망 — 기능·디자인 검토 (2026-10-07)

대상: `/events/:id` 조망 지면(`pages/events/overview`)과 사건 모달. 근거는 헤드리스 브라우저 실측
(최상위 30건 전수 렌더 · 전체 화면 · 스크롤 · 1600/400px · 라이트/다크)과 조망 API 전수 집계.

전수 결과: 30건 모두 조망으로 열림, 페이지 에러 0. 아래는 그 위에서 드러난 것.

## 실측 데이터 (30건)

| 지표 | 값 | 뜻 |
|---|---|---|
| 하위 1~2건뿐인 최상위 | **14 / 30** (1건 11) | 대시보드 지면이 한 줄짜리 간트·매트릭스로 서는 경우가 절반 |
| 하위 시작이 상위 기간 밖 | 12 / 30 (1차대전 9/18, 러불 동맹 9/15) | 7월 위기 사건들이 개전일(7.28) 전 — 상위 기간 정의가 하위와 어긋남 |
| 상위 기간 중 하위 없는 최장 공백 | 1차대전 **99%**, 1차 아편전쟁 91% | 1914.8 이후 4년간 하위 0건 — 전투가 하나도 없다 |
| 상위 자신에 참여국 없음 | 1차대전 (0개국, 하위엔 6개국) | 매트릭스 '상위' 열이 비어 있음 |
| 상위 자신에 개요 없음 | 3건 (1차대전 포함) | 조망엔 원래 상위의 개요 자리가 없다 |
| 날짜 없는 하위 | 0 | 해당 UI 경로는 데이터로 검증 안 됨 |

## P1 — 고장

1. **전체 화면에서 사건 모달이 안 보인다.** 전체 화면은 `Page` 요소 하위만 그리는데 모달은
   `document.body`로 포털된다. 줄을 누르면 강조·`?event=`는 바뀌는데 모달은 화면 밖(실측 스크린샷).
   확인 대화상자·토스트도 같은 문제. → 전체 화면 대상을 문서 전체(`documentElement`)로 하거나,
   전체 화면 중엔 모달을 Page 안으로 포털.

## 기능 — 개선

2. **상위 사건 자신의 개요가 조망에 없다.** 머리에 제목·기간뿐이라 "1차세계대전이 무엇인가"를
   보려면 [문서]로 가야 한다. → 머리 아래 상위 개요(없으면 '개요 쓰기' 안내).
3. **공백 구간을 짚어 주지 않는다.** 1차대전은 하위가 전쟁 첫 두 달에만 있다(공백 99%). 점검이
   목적인 지면에서 가장 큰 결론인데 간트 축을 '상위 기간 전체'로 바꿔야만 보인다. → '하위가 없는
   구간: 1914.8 ~ 1918.11 (4년 3개월)' 경고 줄 + 간트에 빗금.
4. **상위 기간 밖 하위를 표시하지 않는다.** 12건에서 발생. 데이터 오류(상위 기간이 좁음)인지
   의도(전사(前史))인지 화면이 말하지 않는다. → 해당 줄에 '기간 밖' 표지 + 점검 항목.
5. **상위 ↔ 하위 참여국 불일치.** 1차대전은 상위 0개국, 하위 6개국. → '하위의 6개국을 상위에도
   걸기' 한 번에 하는 동작(서버 PUT relatedCountries 재사용).
6. **충실도 지표가 갈래를 무시한다.** 외교·회담 사건에 '수치(사상자·병력)'·'진영'이 비었다고 감점 →
   1차대전 37%는 실제보다 나쁘게 읽힌다. → 갈래별 적용 칸(수치·진영은 전쟁/군사만), 비해당은 회색 '해당 없음'.
7. **하위 1~2건 최상위(14건)에 대시보드가 과하다.** 한 줄 간트·한 칸 매트릭스·막대 하나짜리 분포.
   → 하위 ≤2면 압축 조망(분포·매트릭스 접기) 또는 문서를 기본으로 — **제품 결정 필요**.
8. **거르기가 URL에 없다.** 열린 사건(`?event=`)은 공유되는데 나라·갈래 거르기·축 범위·점검 정렬은
   새로고침하면 사라진다. → `?country=` `?cat=` `?fit=` `?order=`.
9. **모달 번호가 두 가지.** 거른 상태에서 모달은 '2 / 5'(거른 집합 안 위치)인데 간트·점검표 번호는 7.
   → '7번 · 걸린 5건 중 2번째'.
10. **'사건 문서 열기'가 버튼이라 새 탭으로 못 연다.** → 링크(가운데 클릭·⌘클릭 지원).
11. **조망에서 고칠 수 없다.** 점검표가 빈 칸을 보여 주지만 채우려면 문서로 가야 한다. → 모달에서
    개요 한 줄 인라인 편집부터(가장 많이 비는 칸 중 문서 없이 채울 수 있는 것).
12. **발견성.** 좌측 사건 목록·사건 목록 페이지에서 어느 사건이 조망을 갖는지 표시가 없다. → '하위 N' 배지.

## 디자인 — 개선

13. **모바일 간트에서 제목이 스크롤로 사라진다.** 간트는 최소 640px라 가로 스크롤인데 제목 열이
    고정이 아니다(매트릭스 나라 열은 고정). → 제목 열 sticky, 또는 ≤640px에서 세로 목록형.
14. **섹션 내비에 현재 위치가 없다.** 스크롤해도 어느 섹션인지 표시 없음. → 스크롤 위치 강조.
15. **시기별 밀도가 '시작'만 센다.** 25년짜리 차관 사건도 시작한 달 하나로 잡힌다. → '진행 중 하위 수'
    면적 그래프로 바꾸거나 병기.
16. **갈래 패널 아래 빈 공간.** 옆 히스토그램(150px)에 높이가 맞춰져 갈래가 3개면 절반이 빈다.
    → 두 패널을 한 줄 요약형으로 합치거나 갈래를 가로 누적 막대 한 줄로.
17. **매트릭스 '상위' 열이 비면 의미 없는 열.** 1차대전처럼 상위 참여국이 0이면 열 전체가 빈칸. → 숨김(5와 연계).

## 코드

18. 마우스가 줄 위를 지날 때마다 페이지 전체가 다시 그려진다(hover 상태가 페이지에 있음). 18건은
    문제없지만 수백 건이면 버벅인다. → 강조를 CSS 변수/데이터 속성으로, 또는 패널 memo.
