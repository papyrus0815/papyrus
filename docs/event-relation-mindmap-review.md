## 데이터 모양

- event_relation 31행 · 사건 41개 · **섬 10개(가장 큰 섬 9개)** · 최대 차수 5. 관계만으로 그리면 작은 섬들뿐이다.

- 프랑스 혁명: 하위 93 · 국면(묶음 안) 15 · 관계 12(가지 건넘 1).

## 제안 — 두 자리, 같은 그림 문법

### A. 조망 › 연결에 '목록 | 마인드맵' (서버 0 — 조망 응답에 노드·관계가 다 있다)

```
                         ┌ 국면1 ─ 1-1 삼부회 소집
          ┌ 제헌국민의회기 ┤        1-6 바스티유 ──직접 계기──┐
          │              └ 국면2 ─ 1-19 연맹제 ◀────────────┘
프랑스 혁명 ┤
          ├ 입법의회기 ─ … 2-10 8월 10일 ──배경(가지 건넘)──▶ 4-2 철제 금고 ─┐
          └ 국민공회기 ─ …                                    4-3 루이 16세 처형 ◀┘
```

- **뼈대 = 트리**: 루트 가운데, 묶음(가지)을 좌·우로 나눠 균형. 단계 = 루트 → 묶음 → **국면(사건이 아닌 목차 마디, 작은 글자)** → 사건.
  가지 선 색 = 묶음 색(간트·지도와 같은 색), 굵기는 루트에서 멀수록 가늘게.
- **관계 = 가로지르는 선**: 진한 잉크, 선 모양 = 종류(실선 직접 계기·긴 점선 배경…), 방향 종류만 화살촉 — 간트 화살표와 같은 규약.
- **'연결만' 모드(기본)**: 관계가 닿은 사건 + 그 조상 경로만 남긴다 → 프랑스 혁명 93마디가 약 20마디로. '전체' 모드는 모든 마디(가지 접기).
- **접힌 가지로 가는 관계**는 보이는 가장 가까운 조상에 붙이고 '×3' 배지(선이 사라지지 않게).
- 마디 누르면 기존 조망 사건 창, 마우스를 올리면 그 마디의 관계만 진하게·나머지 흐리게, 관계 종류 칩으로 거르기.
- 바깥 연결(트리 밖)은 맨 가장자리 '바깥' 마디(다른 모양)로.

### B. 상세 › 연관에 '마인드맵' (서버: 새 조회 1개)

- 그 사건을 가운데 두고 **2단계까지**: 상위·하위(계층) + 관련(event_relation 양방향) + 관련의 관련.
  NSPM-2(관계 5개)·랑고바르드(섬 9)처럼 **묶음 밖 사건의 인과 사슬**은 여기서만 보인다.
- `GET /events/:id/relation-graph?depth=2` — event_relation·parentEventId를 BFS(마디 상한 200), 소유자 범위 그대로.
- 마디를 두 번 누르면 그 마디를 가운데로 다시 펼친다(지도처럼 걸어 다니기). 한 번 누르면 미리보기 창.

### 공통 구현
- 캔버스 `@xyflow/react`(이미 의존성) — 확대·이동·전체 맞춤·미니맵·키보드 마디 포커스.
- 레이아웃은 직접(새 의존성 0): 잎 개수로 세로 자리를 나누는 가로 트리 + 좌·우 균형. 관계선은 xyflow 커스텀 엣지(베지어).
- 접근성: '목록' 보기가 표 대안(이미 있음). 마디 Enter = 열기.
- 휴대폰: 캔버스 + '전체 맞춤' 기본, 첫 진입은 '연결만'.

## 하지 말 것
- 관계만으로 힘-기반(force) 그래프 — 섬 10개가 흩어져 '한눈에'가 안 된다. 계층이 위치를 정해야 읽힌다.
- 엔티티 그래프(인물·국가)까지 한 캔버스에 — 사건 인과가 묻힌다. 필요하면 다음 단계.
