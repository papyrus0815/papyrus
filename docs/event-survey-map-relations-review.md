# 최상위 사건 조망 — 지도·관련 사건 검토 (2026-11-05)

> "최상위에선 자식 사건을 한눈에 다 볼 수 있는데, 지도나 관련 사건은 못 본다."

## 지금 구조 (근인)

- 조망 탭 데이터 = `GET /events/:id/overview`(event-overview.service). 하위 노드에 **위치는 글(location)만**, 좌표·위치 메모·관련 사건은 없다.
  행은 `include`로 통째로 읽으므로 좌표 컬럼은 이미 메모리에 있다 — 응답에서만 빠진다.
- 조망 화면(overview-sections) 4보기: 전개(언제)·참여(누가)·구성(무엇)·기록 점검(얼마나). **'어디서'와 '왜(서로 어떻게 이어지나)'가 없다.**
  관련 사건(event_relation)을 쓰는 코드가 조망·개요 전개(collection-development)에 0줄.
- 상세의 연관 탭·지도는 **그 사건 하나**만 본다(`getEventRelations(eventId)`·장부 위치 줄). 루트 '프랑스 혁명'은 자기 관계 0·위치 없음이라
  하위 93건에 핀 8개·관계 9개가 있어도 루트에선 하나도 안 보인다.

프랑스 혁명 관계 9개는 모두 하위끼리 — 예: 바스티유 습격 →(직접 계기) 연맹제, 봉건제 폐지 →(배경) 세습 귀족 칭호 폐지,
니스 병합(대불동맹 전쟁) →(배경) 이탈리아 방면군 사령관 부임(이탈리아 원정) — **가지를 건너는 연결**도 있다.

## 제안

### A. 조망에 '지도' 보기 (어디서)
- 하위 전부의 핀을 한 지도에. 번호 = 시작 순서(전개 번호와 같은 수), 색 = 최상위 가지(제헌·입법·대불동맹·국민공회 4색, 팔레트 검증 후).
- 같은 좌표(파리)에 여러 사건 → 한 핀 + 개수 배지, 누르면 목록. 핀·목록 행을 누르면 기존 조망 사건 모달.
- 국면/가지 필터(전개 보기와 같은 줄), '시간 순으로 잇기' 토글(원정 경로처럼 읽힌다 — 이탈리아 원정 몬테노테→몬도비).
- **핀 없는 하위 목록**: '위치 글만 있음 N'·'위치 없음 N'을 지도 옆에 두고 행마다 '지도에 찍기'(기존 위치 모달, 위치 글→검색어 재사용).
  프랑스 혁명은 85건이 비어 있어, 이 목록이 지도를 채우는 작업대가 된다.
- 장부(우측) — 루트에 자기 위치가 없으면 '위치 추가' 대신 **'하위 8곳 · 지도 보기'**(작은 지도 → 조망 지도로).
- 서버: overview 노드에 `locationLatitude·locationLongitude·locationNote` 3필드(조회만, 마이그 0).

### B. 조망에 '연결' 보기 (왜)
- 하위 사이 관계를 **전개 간트 위 화살표**로(원인 → 결과, 관계 종류별 선 모양: 직접 계기 실선·배경 점선·대응·같은 국면).
  간트 머리에 '연결 보기' 토글 — 끄면 지금 그대로.
- 목록 보기도: 관계 종류별 묶음(연관 탭 문법 재사용) · 가지를 건너는 연결은 표시('대불동맹 전쟁 → 이탈리아 원정').
- **바깥으로 나간 관계**(한쪽만 이 트리) — '이 트리 밖과 이어진 사건 N'. 지금 0이지만 사건이 늘면 '프랑스 혁명이 무엇을 낳았나'가 여기 모인다.
- 루트 연관 탭에도 '하위 사건들의 연결 9' 접힌 줄(누르면 조망 연결 보기).
- 서버: overview 응답에 `relations: [{id, fromId, toId, type, description, external: {id,title,startDate}|null}]` — 트리 id 집합으로
  event_relation 한 번 조회(양방향 OR). 마이그 0.

### C. 개요 › 전개 목록에도 작은 표지
- 하위 행에 핀 아이콘(위치 있음)·'→ 2' 연결 수 칩. 누르면 그 사건 연관으로. 목록을 지도/연결 보기로 넘어가는 문.

## 주의
- 트리 상한(MAX_NODES)에 잘린 조망이면 관계·핀도 그 집합 안에서만 — '잘림' 고지에 함께 적는다.
- 같은 좌표 겹침(파리)은 반드시 묶는다 — 아니면 핀 하나 아래 수십 건이 숨는다.
- 색은 가지(정체)를 따른다, 순위가 아니라. 가지가 5개를 넘으면 '그 밖'으로 접는다.

## 추천 순서
A(지도, 서버 3필드) → B 간트 화살표·목록(서버 relations) → C 표지 → 장부 '하위 N곳' 지도.

- 서버 `event-overview.service`: 노드에 `locationLatitude·locationLongitude·locationNote`, 응답에 `relations`(트리 안 사건이 낀 event_relation, 바깥 쪽은 `external`). 마이그 0.
- 조망 탭 6보기: 전개·참여·구성·**지도(어디서)**·**연결(왜)**·기록 점검.
