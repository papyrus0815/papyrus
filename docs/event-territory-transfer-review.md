# 영토 이전(폴란드 분할·할양·병합) 사건 — 분야·기록·폼 검토 (2026-11-05)

> "폴란드 분할처럼 주변 국가가 영토를 뜯어간 사건에 맞는 분야도, 그 데이터를 등록할 폼도 없다."

## 실측

| 항목 | 값 |
|---|---|
| 분할·할양·병합 제목 사건 | 11건 — 9건이 세부 'STATEHOOD(건국·멸망·병합)' |
| 제1차 폴란드 분할 | 분야 **군사** › 세부 건국·멸망·병합, 기간 1763–1773(실제 1772), 하위 1건(아우구스트 3세 사망) |
| 그 사건의 영토 데이터 | 참여국 역할 설명 **자유 글**뿐 — '영토 약 21만km²(국토의 30%) 및 인구 약 450만 명 상실', '약 9만 2천km² 병합' |
| 빠진 것 | **오스트리아(합스부르크)가 참여국에 없음**, 제2차(1793)·제3차(1795) 분할 사건 없음, 셋을 묶는 '폴란드 분할' 묶음 없음 |
| 'STATEHOOD' 기록 칸 | 핵심 기록이 '성립·소멸 국가'(FOUNDED/DISSOLVED 역할) — 1차 분할은 연방이 **소멸하지 않았다** → 칸이 사건과 맞지 않음 |
| 할양 면적 지표 `territory.area_ceded` | 정의만 있고 관측 0건, 사건 단위 합계 하나(누가 얼마를 가져갔는지 못 담음) |
| 조약 종류 TERRITORIAL·BORDER | 정의만 있고 0건 · 조약 조항(TreatyTerm)은 자유 글 |
| 행정구역 | 17행, 역사 국가 소속 0행 · 한 구역 = 한 나라 고정(갈리치아가 연방 → 합스부르크로 '넘어간' 것을 못 적음) |
| 국가 계승(Transition) | 전신 → 후신만. 영토가 **이미 있는 나라들에 흡수**되는 분할은 계승이 아니라 표현 불가 |

**근인** — 이 앱의 모든 기록은 "누가 참여했나(참여국·진영)"와 "무엇이 생기고 사라졌나(건국·멸망)"뿐이고,
"**무엇이 누구에게서 누구에게로 넘어갔나**"를 담는 자리가 없다. 그래서 영토 이전이 자유 글(역할 설명)로 흩어진다.

## 분야를 늘릴까, 세부를 늘릴까 → 세부(+기록)

분야(정치·외교·군사…)는 '무엇에 관한 일인가'이고 색·필터 축이다. 영토 이전은 **꼴**이라 여러 분야에 걸친다 —
정복 뒤 할양(군사), 분할 조약(외교), 알래스카 매입(경제), 국민투표 병합(정치). 분야로 만들면 이 사건들을 한 칸에 몰아
색·필터가 '주제'를 잃는다. 기존 설계(분야 9 × 세부 28, 독립 두 축)와 같은 이유로 **세부 '영토 변경'**을 추가하고,
그 세부가 부르는 **새 기록 '영토 이전'**을 만든다.

## 제안

### A. 세부 분야 `TERRITORY` — 영토 변경(할양·분할·병합·교환·매입)
- 기본 분야 외교, 핵심 기록 = **영토 이전**, 함께 = 참여국·조약·수치·성립·소멸 국가(3차 분할처럼 나라가 사라질 때).
- STATEHOOD 라벨은 '건국·멸망·독립'으로 좁힌다(병합은 이리로) — 나라 전체 병합은 영토 이전 1줄 + 멸망 역할.

### B. 새 기록 `event_territory_transfer` (한 줄 = 한 덩어리 영토가 한 나라에서 다른 나라로)
| 칸 | 예(1차 분할) |
|---|---|
| 내준 나라 (역사/현대 dual FK) | 폴란드-리투아니아 연방 |
| 받은 나라 (dual FK, 없으면 '자유시·위임통치' 같은 이름) | 프로이센 왕국 |
| 지역 이름 (+ 선택: 행정구역 FK) | 왕령 프로이센(단치히·토룬 제외) |
| 방식 enum | PARTITION 분할 · CESSION 할양 · ANNEXATION 병합 · EXCHANGE 교환 · PURCHASE 매입 · OCCUPATION 점령 · RETROCESSION 반환 · LEASE 조차 |
| 면적 km² · 인구 (숫자, 선택) | 36,300 · 580,000 |
| 근거 조약 (선택, Treaty FK) | 1772년 상트페테르부르크 조약 |
| 발효 시점 (구조화 연·월·일, BC 안전) | 1772-08-05 |
| 메모 | — |

- **참여국 역할은 이 표에서 나온다**: 내준 나라 = 피해국(VICTIM), 받은 나라 = 수혜국(BENEFICIARY)을 등록 때 자동 채움(이미 있으면 그대로).
- 면적·인구는 지표(observation)가 아닌 이 줄의 칸 — 지표는 '사건의 한 숫자', 이건 '어느 땅의 크기'라 단위가 줄이다.
  사건 머리의 '할양 면적 합계'는 이 줄들의 합으로 계산(지표 프리셋 대체).

### C. 보이는 곳
1. **사건 상세 '영토 이전' 섹션** — 받은 나라별로 묶은 표 + 합계 막대(러시아 9.2만 · 오스트리아 8.3만 · 프로이센 3.6만km²,
   연방 −21.1만 = 국토의 30%). 각 줄의 근거 조약 링크.
2. **등록 모달** — 세부 '영토 변경'을 고르면 '영토 이전' 줄 입력(내준 나라 → 받은 나라 · 지역 · 방식 · 면적), 참여국 자동 채움.
3. **국가 상세 '영토 변천'** — 그 나라가 얻고 잃은 줄을 시간순으로(연방: 1772 −21만 → 1793 −30만 → 1795 소멸).
   이 앱에 처음 생기는 '국경이 움직인 이력'.
4. (후속) 연결 지도·조망 지도에 지역 중심 좌표로 화살표 — 행정구역 FK가 채워진 줄만.

### D. 데이터
- 1차 분할 고치기: 분야 외교, 세부 영토 변경, 기간 1772-02-17(비밀 협약)~1773-09-30(세임 비준), 오스트리아 대공국(합스부르크 군주국) 참여국 추가,
  역할 설명의 면적을 영토 이전 3줄로 옮김.
- 제2차(1793, 러시아·프로이센)·제3차(1795, 3국, 연방 멸망) 사건과 묶음 '폴란드 분할(1772–1795)' 추가.
- 나머지 분할·할양·병합 9건은 세부만 재분류(줄 입력은 사용자 확인 뒤).

## 배치
1. 스키마·API — 표 1개 + enum 1개 + EventType `TERRITORY`(마이그), CRUD(사건 소유권 가드 재사용), 참여국 자동 채움.
2. 상세 섹션 + 레지스트리(세부·기록·라벨) + 등록 모달 입력.
3. 국가 상세 '영토 변천'.
4. 폴란드 분할 데이터(1·2·3차 + 묶음) 시드 · 기존 9건 재분류.

## 기각
- 새 분야 '영토' — 위 이유(분야는 주제 축).
- 지표(observation)만으로 — 사건 한 숫자라 '어느 땅이 누구에게'를 못 담고, 참여국 줄 지표로 해도 지역·방식·근거 조약이 없다.
- 행정구역에 '소속 기간'을 달아 이전을 표현 — 역사 국가 행정구역이 0행이라 당장 쓸 데이터가 없고, 지역 이름 자유 입력 + 선택 FK로 충분.
- 국경 폴리곤(GeoJSON) — 데이터 수급이 별개 프로젝트.
