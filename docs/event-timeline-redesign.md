# 사건 타임라인 재설계 — 시대 드릴다운 (v4)

> 2026-08-10. 사용자 문제 제기: "사건 타임라인은 전혀 사용할 수가 없다. 너무나도 복잡하고
> 가시성이 떨어진다. 새로 설계하라."
> 대상: `/events` 카탈로그의 기본 뷰인 타임라인 (`widgets/event-timeline`, 5,666줄 단일 파일).

## 1. 진단 — 왜 못 쓰는가

기존 v3는 **연속 픽셀 축 간트(gantt)** 표현을 골랐고, 역사 데이터(수천 년 스팬 + 극도로
불균등한 밀도 + 한글 제목 10~20자)와 구조적으로 충돌한다. 이후의 모든 복잡성은 그 충돌을
보상하는 장치들이다.

1. **조작 체계 7종** — 연속 줌(프리셋 8단·Ctrl+휠·핀치·`+/-/0` 단축키), 팬 3종(Space+드래그·
   미들클릭·터치), 미니맵 brush, 연도점프 입력, fit-all. 첫 진입에 *온보딩 코치마크*가 뜨는
   UI — 설명서가 필요한 시점에서 이미 실패.
2. **시각 인코딩 9종 동시** — 색=카테고리, 폭=기간, 모양(pill 길이)=시점/기간, 클러스터 +N,
   중요도=내부 흰 점/링/dashed, depth=투명도, 레인 하단 밀도 띠, 오늘 마커, 선택 가이드.
   *모양 범례 popover*가 따로 필요한 이유.
3. **이름이 구조적으로 안 보임** — 라벨은 2행 스태거 + 중요도 steal + Shift+클릭 핀 + 리더선
   으로 경쟁하고, 밀집 구간에서는 대부분 탈락한다. 탈락분을 툴팁·우측 레일·팝오버 2종(클러스터/
   오버플로)이 보완한다. 즉 **익명 마크가 기본이고 이름이 예외** — 카탈로그의 목적과 정반대.
4. **예측 불가** — 줌을 바꾸면 라벨이 생멸하고 클러스터가 붙었다 떨어지며, `+N`이 세 가지 다른
   의미(클러스터·레인 오버플로·레일 절단)로 쓰인다. 사용자는 "무엇이 보일지"를 예측할 수 없다.
5. **상태 기계 비대** — 26개 state/ref, 스크롤 동기화를 위한 직접 DOM transform, roving
   tabindex SVG, 첫 진입 프레이밍 휴리스틱(최밀집 10년 중앙 배치) 등. 5,666줄 단일 파일.

핵심 교훈: **밀집을 라벨 배치 알고리즘으로 푸는 것은 실패했다.** 표현 자체를 바꿔야 한다.

## 2. 설계 원칙

- **P1. 익명 마크 금지** — 화면의 모든 표식은 이름을 갖거나, 클릭 시 이름 목록이 열리는
  명시적 집계다. 툴팁·확대 없이는 정체를 알 수 없는 점을 그리지 않는다.
- **P2. 스크롤 축은 세로 하나** — 가로 스크롤·팬·연속 줌 폐지. 시간 창은 항상 화면 폭에 맞다.
- **P3. 시간 탐색은 이산 3단 드릴** — 전체(세기) → 세기(10년 구간) → 10년(연도).
  클릭으로 내려가고 브레드크럼으로 올라온다. 어느 단계에서 무엇이 보일지 항상 같다.
- **P4. 인코딩 3개** — 색=카테고리, 가로 위치/폭=시간(현재 창 안), 볼드/글리프=핵심.
  나머지(모양·투명도·내부 마커·dashed) 전부 폐지.
- **P5. 설명이 필요 없는 UI** — 온보딩 팁·모양 범례가 필요 없어지는 것이 목표.

## 3. 새 구조 — 세로 스택 3층

```
[사건 타임라인 카드]
 ├ 헤더: 제목 · 총 건수·로드 상태 · 카테고리 범례(표시/숨김 토글)
 ├ ① 시대 내비게이터  ← 시간 축 조작의 유일한 지면 (브레드크럼 포함, 항상 노출)
 └ [내부 세로 스크롤 영역]
    ├ ② 기간 밴드     ← 세기·10년 단계에서만. 라벨 항상 보이는 가로 막대
    └ ③ 연표 리스트   ← 창 안 전 사건, 하위 버킷 그룹 헤더 + 플랫 행
```

(내비게이터는 sticky 대신 **내부 스크롤 영역 위에 상시 배치** — 카드 `overflow:hidden`과
sticky의 스크롤포트 상호작용 함정을 피하면서 같은 효과를 얻는다.)

### ① 시대 내비게이터 (미니맵의 승격)
- 현재 단계의 버킷을 **화면 폭 균등 분할** 히스토그램으로: 높이=사건 수,
  색=카테고리 스택(범례와 동일 색). 버킷 아래 라벨(세기/구간/연도).
- **전체 단계**: 사건이 있는 세기만 표시, 빈 세기 연속 구간은 `⋯ N세기 공백` 슬림 표지로
  압축(목록 뷰의 '기록 없음' 표지와 같은 규약). BC는 음수 세기(`기원전 5세기`).
- **세기 단계**: 해당 세기의 10개 10년 구간(세기 규약 1501~1600에 정확히 10등분,
  예: 1801–1810 … 1891–1900). 0건 구간도 고정 노출 — 공백이 곧 정보.
- **10년 단계**: 10개 연도. 클릭하면 리스트의 그 연도 그룹으로 스크롤+플래시.
- 브레드크럼 + 이전/다음(‹ ›) 스텝 버튼(세기·10년 단계). 키보드: ←/→ 버킷 이동(roving),
  Enter 드릴, Backspace/Esc 상위로.
- 날짜 미상 사건은 우측 끝 `미상 N` 칩 → 미상 창(리스트만).

### ② 기간 밴드 — "동시대성·기간"의 지면
- 창과 겹치는 **기간 사건**(현재 축척에서 막대 폭 ≥ 14px)만 가로 막대로. 색=카테고리,
  높이 16px(기존 시각 규약 유지), **라벨은 항상 막대 밖·항상 노출**.
- 행 수 제한 없음 — 겹치면 아래 행으로 내려갈 뿐(first-fit 패킹, 라벨 폭 포함 충돌 계산).
  탈락·스틸·핀 개념 자체가 없다.
- 창 밖으로 이어지는 사건은 가장자리 클램프 — 잘린 쪽 모서리를 직각으로 렌더하고
  라벨에 실제 연도 범위를 병기한다(`나폴레옹 전쟁 (1795~1815)`).
- 전체(세기) 단계에서는 그리지 않는다 — 세기 폭에서 개별 막대는 다시 익명 마크가 되기 때문.
  그 단계의 조망은 내비게이터 히스토그램이 담당한다.

### ③ 연표 리스트 — 이름의 정본 (레일의 승격)
- 창 안 **모든** 사건을 하위 버킷 그룹(전체→세기별 / 세기→10년 구간별 / 10년→연도별)으로.
- 행 = `연도 · 카테고리 점 · 제목 · [핵심|주요] · 기간(1914–1918) · ↳하위(depth)`.
  클릭 = 기존 상세 드로어(onSelectEvent). 선택 행 하이라이트, 밴드 막대와 상호 강조.
- 소속 규약: **리스트·카운트는 시작 시점 기준**(사건은 정확히 한 버킷에 1회 — 모수 일치),
  밴드는 겹침 기준(현존감) + 클램프 표기. 이 차이는 밴드 라벨의 연도 병기로 드러난다.

## 4. 기존 기능 처분표

| v3 장치 | v4 처분 |
|---|---|
| 미니맵 카드 | 내비게이터로 **승격** (같은 스택색 히스토그램이 곧 조작면) |
| 연속 줌·팬·연도점프·fit-all | 이산 3단 드릴 + 브레드크럼 + ‹› 스텝으로 **대체** |
| 레인 축(카테고리/대륙/국가) + `lane` URL | **폐지** — 색=카테고리 유지, 대륙/국가는 공유 필터 담당 |
| 카테고리 숨김(범례 토글) + `hide` URL | **유지** (5차 필터 검토 규약 그대로) |
| 클러스터·+N 배지·팝오버 2종 | **폐지** — 리스트가 전수 표시라 불필요 |
| 우측 사건 레일 | 본문 리스트로 **승격** |
| 라벨 스태거·steal·핀·리더선 | **폐지** — 라벨 상시 노출이 구조적으로 보장 |
| 툴팁 | **폐지** — 행/막대 자체가 정보를 담음 (`title` 속성만 보조) |
| SVG/PNG/JSON 내보내기 | **폐지** — JSON은 페이지 툴바 내보내기가 이미 담당 |
| 오늘 마커·depth 투명도·중요도 내부 마커 | **폐지** (중요도는 리스트 칩·볼드로) |
| 온보딩 팁·모양 범례 | **불필요** (P5) |
| 전량 자동 로드(hasMore 소진·상한·재시도) | **유지** (전 시대 조망에 필수) |
| 선택 사건 자동 스크롤 | 창 밖이면 "창 밖 · N으로 이동" 배너로 **대체**(예측 가능) |
| wideMode(집중 보기) | **유지** — 내비게이터를 슬림 모드로 압축 |

## 5. 상태·URL 계약

- 창 상태 `TimelineWindow`: `null`(전체) · `{century}` · `{span10 시작연도}` · `미상`.
  위젯은 비제어로도 동작, 카탈로그는 페이지가 소유하고 URL `tlw`로 정본화
  (`tlw=c19`·`tlw=c-1`·`tlw=d1871`·`tlw=u`). `lane` 파라미터는 파서에서 제거(구 URL은 무시).
- 유지되는 위젯 props: `flattenedHierarchy`(필터 매칭분만) · `events` · `selectedEventId` ·
  `dbCategories` · `onSelectEvent` · 로딩 4종 · `wideMode` · `hiddenCategories` 3종.
  제거: `continents` · `countries` · `groupBy` · `onGroupByChange`.
- 날짜 파싱은 기존 규약 그대로 `parseIsoDateParts`(부호 연도, 네이티브 Date 금지),
  세기 경계·라벨은 `getCentury`/`centuryYearRange`/`formatCenturyLabel`/`formatYearLabel` 재사용.
- 시작일 없는 사건은 버리지 않는다(미상 창) — v3는 조용히 drop했다.

## 7. 구현 결과 (2026-08-10)

- 위 구성대로 전면 구현. 위젯 5,666줄 단일 파일 → 4파일 합계 약 1,900줄
  (모델 660 + 내비게이터 560 + 밴드 250 + 리스트 300 + 조립 640, 스펙 별도).
- '전체 초기화'는 시간 창·카테고리 숨김도 되돌리고, 활성 칩에 `타임라인 창 · 19세기`가
  참여한다(칩·해제 수 모수 일치 규약 유지). 구 URL의 `lane=`은 첫 write에서 정리.
- 검증: tsc 0 에러 · 신규 파일 lint 0 · jest 764 중 761 통과(실패 3은 기존
  country-detail·rich-text 스위트로 본 작업과 무관). 모델 스펙 23케이스
  (BC 경계·세기 10등분·패킹 무탈락·URL 왕복) 신규.
- 미실시: 브라우저 실화면 검증(크롬 확장 미연결) — 다음 세션에서 밀집 세기·BC·
  모바일 폭·다크 모드를 실측할 것.
