# `/government` 페이지 디자인 개선 검토 (`/events` 디자인 기준)

> 작성일: 2026-11-15  
> 참조 기준: `docs/event-page-infographic-review-v2.md`, `docs/event-detail-review.md`, `apps/web-admin/src/pages/events/*`

---

## 1. 배경 및 핵심 진단

`/events`(사건) 카탈로그와 상세 지면은 수차례의 인포그래픽·원장(Ledger)·상세 개편을 거치며 다음 5가지 핵심 원칙을 확립했다.

1. **회색 띠 적층 폐기 및 여백·타이포 위계화**: 별도 통계 바·회색 세기 띠를 걷어내고, 열 머리글 안에 건수를 통합하며 세기 구분은 상단 여백(`--century-gap`)과 1px 리더선으로 처리한다.
2. **시간을 문자열이 아닌 위치·길이로 부호화**: 전폭 균등 세기 슬롯 + 10년 히스토그램 + 빈 세기(`⋯`) + 실시간 뷰포트 창(`Window`)으로 전체 시간축을 조망하고, 각 행은 `[시작] · [종료] · [기간 막대+연수]`로 재임/지속 길이를 시각화한다.
3. **컨테이너 쿼리 기반 3단 적응형 열 사다리 (`summary` → `ledger` → `atlas`)**: 고정 px 열 때문에 광폭 화면에서 국가명·정당명은 잘리고 제목 칸만 빈 여백으로 늘어나는 현상을 막기 위해, 컨테이너 폭에 따라 다중 가변 트랙(`1.5fr : 1fr : 0.8fr`)으로 확장한다.
4. **단일 탭 정거장(Roving TabIndex) 및 포털 뷰 유틸리티**: 목록 전체를 단일 Tab 정거장으로 묶어 `↑`/`↓` 화살표 탐색을 지원하고, 표시 설정(`⋯`)은 포털(`createPortal` + `useAnchoredPosition`)로 클리핑 없이 렌더링한다.
5. **상세 지면의 연속 흐름 띠 + 우측 Sticky 사실 장부 + 빈 섹션 접기(`FillInStrip`)**: 히어로 직하단에 전후 맥락 흐름 띠를 두고, 우측 사실 장부에 핵심 메타데이터를 고정하며, 비어 있는 부가 섹션은 본문에서 접어 하단 `'더 채울 수 있는 기록'` 스트립으로 모은다.

반면 `/government`는 단일 파일(`government-catalog.page.tsx`, 4,609줄)에 초기 원장 시안이 머물러 있어 다중 회색 바 적층, 2줄 행의 제목-수반 중복 출력, 비비례 시대 버튼 줄, 키보드 포커스 불가 행, 빈 카드(`EmptyCard`)가 나열되는 상세 지면 구조가 남아 있었다.

## 2. 영역별 개선 내역

### A. 상단 도구줄 (`TopToolbarCard`)
- **컨테이너 쿼리 3존 그리드 (`govtoolbar`)**: `[검색] | [내각·기관 탭 + 핵심 필터] | [시점 단면·뷰 유틸·등록 CTA]` 구조로 정돈하고, 컨트롤 높이를 `34px`(모바일 `40px`)로 통일.
- **검색 Pending 스피너 & 모바일 FAB**: `useDeferredValue` 전환 중 스피너를 노출하고, 모바일(`<=640px`)에서는 `/` 단축키 배지를 숨기며 등록 CTA를 우하단 FAB으로 분리.
- **초기화 되돌리기(Undo) 토스트**: `전체 초기화` 클릭 시 직전 URL 필터·접힘 상태를 스냅샷해 `되돌리기` 액션 토스트 제공.
- **포털 기반 표시 설정 메뉴**: `createPortal` + `useAnchoredPosition` + `useOverlayEscape` 기반으로 클리핑을 방지하고, 열 숨기기(`hiddenColumns`) 토글을 추가.

### B. 비례 시대 띠 (`GovernmentEraStrip`)
- **전폭 균등 세기 슬롯 + 10년 히스토그램 + 빈 세기(`⋯`) 압축**: `era-strip.lib.ts`의 `buildEraAxis`를 활용해 기록이 없는 세기 구간을 `⋯`로 접고, 세기 내 10년 단위 분포를 막대 높이로 시각화.
- **장기 내각·기관 스팬 라인(`SpanLine`) & 뷰포트 창(`Window`)**: 다년 지속 내각/기관을 상단 3레인 수평 선으로 표시하고, 현재 스크롤 화면에 보이는 연도 범위를 실시간 창(`Window`)으로 오버레이.
- **중복 프리셋 제거**: 툴바의 `시점 연도` 컨트롤과 중복되던 우측 `동시대 단면: 1914 1939...` 버튼 묶음을 정리하고, 목록 카드 바깥의 독립된 전폭 개관 띠로 배치.

### C. 원장 목록 표면·헤더·행 기하 (`LedgerCardSurface` & `LedgerRow`)
- **3중 회색 바 제거 & 인라인 건수 통합**: `LedgerStatsSummary`를 없애고 열 머리글(`내각 · 수반` / `국가 기관`) 옆에 `조건 일치 N건 / 등록 전체 M건`을 통합.
- **열 머리글 직접 클릭 정렬**: `시작`, `기간`, `각료/인사`, `사건/산하` 열 머리글 클릭 시 정렬 방향 전환(`▾`/`▴`).
- **1줄 고밀도 행 & 제목-수반 중복 제거**: `getCabinetDisplayTitle`이 `${수반명} ${직위}` 폴백일 때 아래 줄에 같은 텍스트가 반복되던 문제를 제거하고, 고유 내각명이 있을 때만 수반 칩을 인라인 보조 토큰으로 표시.
- **`[시작] · [종료] · [기간 막대+연수]` 시간 부호화**: `128px` 문자열 칸 하나에 구겨 넣던 기간을 시작열·종료열·비례 막대(`DurationFillBar`)가 포함된 기간열로 분리.
- **3단 적응형 열 사다리 (`govcard` 컨테이너 쿼리)**: 화면이 넓어질수록 제목(`1.5fr`), 정당/계보(`1fr`), 국가(`0.8fr`)가 함께 넓어져 긴 역사 국가명과 정당명이 잘리지 않도록 개선.
- **Roving TabIndex 키보드 내비게이션**: 행에 `role="listitem"`, `tabIndex={0|-1}`, `↑`/`↓`/`Home`/`End`/`Enter`/`Space` 핸들러 및 `aria-live="polite"` 알림 적용.

### D. 우측 상세 드로어 (`GovernmentDetailDrawer`)
- **반응형 스플릿 폭**: `>1400px`에서 `clamp(400px, 22vw, 580px)`, 모바일(`<=640px`)에서 `100dvw` + 백드롭 적용.
- **필터 조건 밖(`isOutOfScope`) 배너**: 선택 항목이 현재 필터 목록 밖에 있을 때 이유를 설명하고 `[필터 초기화]` 버튼을 제공하는 안내 배너 추가.
- **공유 버튼**: Web Share API 및 클립보드 복사 폴백을 지원하는 상세 링크 공유 버튼 추가.

### E. 내각·기관 상세 지면 (`GovernmentCabinetDetailPage` / `GovernmentDepartmentDetailPage`)
- **연속 흐름 띠 (`ContinuityFlowStrip`)**: 히어로 바로 아래에 `[← 전임 내각] · 현재 내각 · [후임 내각 →]` 및 `[상위 기관] › [← 전신] · 현재 기관 · [후신 →]` 흐름 띠를 배치해 즉각적인 시계열·계보 이동 지원.
- **우측 Sticky 사실 장부 (`DetailFactsRail`)**: 좌측 본문과 우측 사실 장부(국가·정부형태·기간·재임 일수·수반·참여 정당·각료 수·소재지·법적 근거·예산·인원·동시대 수장 비교) 2단 구조로 개편하고 빈 값 행은 생략.
- **빈 섹션 접기 & `FillInStrip` ('더 채울 수 있는 기록')**: 비어 있는 부가 섹션(여당·연정, 주요 업적, 관여 사건, 산하 군부대 등)의 빈 박스 노출을 접고, 하단 `'더 채울 수 있는 기록'` 스트립에서 원클릭으로 추가·연결할 수 있도록 개선.
