# 바뀌는 중앙부처 등록 및 수장 등록 가이드

예: **중앙정보부 → 안기부 → 국정원**처럼 이름이 바뀌는 기관을 등록하고, 각 시기별 수장(장관)을 등록하는 방법입니다.

---

## 행정부처(중앙부처) 등록 기능은 어디 있나?

**경로:** 국가 상세 페이지 → **행정조직** 탭 → **중앙부처** 서브탭

1. 국가(현대 국가)를 연 뒤, 상단 탭에서 **행정조직** 클릭.
2. 행정조직 안에서 **역대 수반 / 행정부 / 중앙부처 / 통계** 중 **중앙부처** 클릭.
3. **중앙부처 현황**이 카테고리별로 나옵니다.  
   - **카테고리가 없으면** 먼저 상단 **카테고리 설정**으로 카테고리(예: 국방·외교·정보)를 추가합니다.
4. 각 카테고리 섹션에서:
   - 그 카테고리에 속한 부처 카드가 나열되고, **+ 부처 등록** 버튼으로 같은 카테고리에 부처를 추가할 수 있습니다.
   - **같은 카테고리에 여러 부처**를 둘 수 있어서, 예를 들어 **국방** 카테고리에 **전쟁부**와 **국방부**를 함께 등록할 수 있습니다.

**정리:** 행정부처 등록은 **중앙부처 탭**에 있고, **카테고리별**로 **부처 등록**(또는 **+ 부처 등록**) 버튼으로 합니다.

**같은 카테고리에 여러 부처:** 한 카테고리(예: 국방)에 **전쟁부**와 **국방부**를 둘 다 넣을 수 있습니다. 카테고리 섹션 안에 부처 카드가 여러 개 나열되고, **+ 부처 등록**으로 같은 카테고리에 부처를 더 추가하면 됩니다.

## 만철·관동군 같은 “조직”은 어떻게 등록하나? (일본 제국 등)

**남만철주식회사(満鉄)·관동군(関東軍)·대만총독부** 같은 것은 **중앙부처가 아니라 “조직(Organization)”**으로 등록합니다.

- **중앙부처(AdministrationDepartment)**: 국가의 행정 부처(국방부, 외교부 등). 행정조직 → 중앙부처 탭에서 **국가별**로 등록.
- **조직(Organization)**: 회사·군대·총독부 등. **조직** 전용 메뉴에서 등록.

**조직(행정기구) 위치:** 별도 상단 메뉴가 없습니다. **국가 상세 → 행정조직 탭 → 행정기구** 서브탭에서 해당 국가에 소속된 조직을 보고, **조직 등록**으로 만철·관동군·총독부 등을 추가합니다. (국가에 종속.)

**등록 경로:** 국가 선택 → **행정조직** → **행정기구** 탭 → **조직 등록** (또는 **`/organizations/new?countryId=국가ID`**)

1. **조직** 페이지에서 **조직 등록**으로 만철(南滿洲鐵道株式會社), 관동군, 대만총독부 등을 생성합니다.
2. **국가 상세 → 행정조직 → 관직 정의**에서, 해당 조직에 연결된 직위를 만듭니다.  
   - 예: 직위명 **만철 총재**, **관동군 사령관** → **소속 조직**에 위에서 만든 조직 선택. (행정 부처가 아니라 **조직**을 선택.)
3. 인물의 **재임**을 등록할 때 그 직위를 선택하면, “만철 역대 총재”, “관동군 역대 사령관”처럼 **조직 역대 수장**으로 조회·표시됩니다.

**정리:** 만철·관동군은 **중앙부처 탭이 아니라 조직(Organization)**으로 등록하고, **관직 정의**에서 “소속 조직”으로 연결한 뒤 재임을 넣으면 됩니다.

## 전신·후신(개편 이력)은 어떻게 등록하나? (예: 미국 전쟁부 → 국방부)

**후신만** 등록하면 됩니다. 전신은 자동으로 연결됩니다.

- **후신 부처**: 부처 등록/수정 폼에 **후신 부처** 필드가 있습니다.  
  “이 부처가 개편·통폐합되어 이어지는 다음 부처”를 선택합니다.
- **전신**: 별도 필드는 없습니다.  
  A 부처의 **후신 부처**를 B로 넣으면, B 입장에서는 A가 전신으로 저장됩니다.

**미국 예: 전쟁부(War Department) → 국방부(Department of Defense)**

1. **국방부** 먼저 등록  
   - 부처명: 국방부 (또는 Department of Defense)  
   - 설립일: 1947-07-26 등  
   - 후신 부처: (없음)
2. **전쟁부** 등록 후 수정  
   - 부처명: 전쟁부 (또는 War Department)  
   - 설립일·폐지일: 해당 연도  
   - **후신 부처**: 위에서 만든 **국방부** 선택

이렇게 하면 “전쟁부 → 국방부” 개편 이력이 저장되고, 전신/후신 관계는 후신 부처만 지정해서 쓰면 됩니다.

## 1. 바뀌는 중앙부처를 어떻게 등록하나?

중앙부처는 **국가 상세 → 행정조직 탭 → 중앙부처**에서 등록합니다.  
**설립일·폐지일·후신 부처**를 넣으면 “이름이 바뀌는 기관”을 이어서 표현할 수 있습니다.

### 등록 순서 (권장)

**가장 나중 기관부터** 넣으면 후신 선택이 쉽습니다.

| 순서 | 부처명   | 설립일   | 폐지일   | 후신 부처 |
|------|----------|----------|----------|-----------|
| 1    | 국정원   | 1999-01-21 | (비움)   | (없음)    |
| 2    | 안기부   | 1981-04-01 | 1999-01-20 | 국정원    |
| 3    | 중앙정보부 | 1961-06-10 | 1981-03-31 | 안기부    |

- **국정원**: 후신 없음(현재 기관). 폐지일 비움.
- **안기부**: 후신 = 국정원. 폐지일 = 국정원 설립 전일.
- **중앙정보부**: 후신 = 안기부. 폐지일 = 안기부 설립 전일.

### UI에서 하는 일

1. **국가 선택** 후 **행정조직** 탭 → **중앙부처** 서브탭 이동.
2. **부처 등록** (또는 목록에서 부처 추가 카드) 클릭.
3. 폼에서:
   - **부처명**: 예) 국정원
   - **카테고리**: 예) 정보·보안 (해당하는 카테고리 선택, 없으면 카테고리 먼저 등록)
   - **설립일**: 날짜 선택
   - **폐지일**: 폐지된 기관만 선택 (현재 기관이면 비움)
   - **후신 부처**: 개편으로 이어지는 다음 기관 선택 (이미 등록된 부처만 목록에 뜸)
4. **등록** 후, 이전 시기 기관(안기부 → 중앙정보부)을 같은 방식으로 등록하며 **후신**만 위에서 만든 부처로 지정.

이미 부처를 먼저 만들어 두었다면, **수정**에서 설립일·폐지일·후신 부처만 넣어도 됩니다.

## 2. 바뀌는 중앙부처의 수장들은 어떻게 등록하나?

“수장”은 **관직 정의(직위)** + **재임(Tenure)** 으로 표현합니다.  
**부처별로 직위를 하나씩 만들고**, 그 직위로 **각 행정부(정권)마다 재임**을 넣으면 됩니다.

### 2-1. 부처별 직위 정의 만들기

**국가 상세 → 행정조직 탭 → 관직 정의** (또는 해당 국가의 관직 정의 섹션)에서:

1. **관직 정의 등록** 클릭.
2. 다음처럼 **부처마다 하나씩** 직위를 만듭니다.

| 직위명(제목)   | 직위 유형     | 행정 부처   |
|----------------|---------------|-------------|
| 중앙정보부장   | 각료/장관     | 중앙정보부  |
| 안기부장       | 각료/장관     | 안기부      |
| 국정원장       | 각료/장관     | 국정원      |

- **직위 유형**: 각료/장관(`CABINET_MINISTER`) 등.
- **행정 부처**: 위에서 만든 **중앙정보부 / 안기부 / 국정원** 중 하나를 선택.

이렇게 하면 “중앙정보부 수장”, “안기부 수장”, “국정원 수장”이 각각 한 직위로 정의되고, 행정부 그리드에서 **부처 칸**과 연결됩니다.

### 2-2. 행정부별로 수장(재임) 등록하기

**국가 상세 → 행정조직 탭 → 행정부**에서:

1. 해당 **정권(행정부)** 카드를 선택해 “선택한 정권의 행정부” 영역을 띄움.
2. **정보·보안** 같은 해당 **카테고리**의 부처 카드에서 **각료 추가** 클릭.
3. **인물 선택** 후, 사이드바에서:
   - **직책(직위)**: 그 정권 시기에 맞는 직위를 선택  
     (예: 1963년 내각이면 “중앙정보부장”, 1982년이면 “안기부장”, 2000년이면 “국정원장”).
   - **소속 행정부**: 이미 선택한 행정부로 고정됨.
   - **취임일·퇴임일** 입력.
4. **등록**하면, 그 행정부의 해당 부처 칸에 수장이 표시됩니다.

즉, **시기(행정부)에 맞는 직위**를 골라 재임을 넣으면,  
중앙정보부장 / 안기부장 / 국정원장이 각각 “중앙정보부 / 안기부 / 국정원” 칸에 들어갑니다.

## 요약

| 단계 | 어디서 | 무엇을 |
|------|--------|--------|
| 1. 부처 등록 | 행정조직 → 중앙부처 | 중앙정보부, 안기부, 국정원을 각각 부처로 등록. 설립일·폐지일·**후신 부처**로 연결. |
| 2. 직위 정의 | 행정조직 → 관직 정의 | 부처별로 “중앙정보부장”, “안기부장”, “국정원장” 직위를 만들고 **행정 부처**에 연결. |
| 3. 수장 등록 | 행정조직 → 행정부 | 정권 선택 → 해당 부처 칸에서 **각료 추가** → 인물·**시기에 맞는 직위**·기간 입력 후 등록. |

데이터 구조상 **부처**는 설립/폐지/후신으로 “이름이 바뀌는 기관”을 표현하고, **직위**는 부처별로 나누어, **재임**은 정권·기간별로 그 직위를 선택해 넣는 방식입니다.

## 행정기구·행정부처 입력 가능 필드 (상세)

### 행정기구(조직) — 넣을 수 있는 정보

| 필드 | 설명 | 비고 |
|------|------|------|
| **이름** | 공식 명칭 (필수) | 예: 남만주철도주식회사, 관동군 |
| **약칭/두문자** | shortName | 예: 만철, MOFA |
| **로컬 명칭** | 현지어/한자 등 | 예: 南滿洲鐵道株式會社 |
| **유형** | 조직 유형 | 정부기관, 기업, 군사학교, 정당, 국제기구, NGO, 노동조합, 교육기관 등 |
| **활동 범위** | scope | 국제 / 초국가 / 지역 / 국가 / 광역·기초 / 지역·도시 |
| **소속 국가 (현대)** | countryId | 현대 국가 1개 |
| **소속 국가 (역사적)** | historicalCountryId | 역사적 국가 1개 (현대와 둘 중 하나) |
| **설립일** | foundedDate | 조직 설립일 |
| **해체일** | dissolvedDate | 폐지·해산일 (없으면 현존) |
| **공식 웹사이트** | websiteUrl | URL |
| **로고 URL** | logoUrl | 이미지 URL |
| **설명** | description | 역할·목적·주요 활동 (텍스트) |
| **이념/노선** | ideology | 정당·노조 등에서 활용 |

스키마에는 **본부 도시**(headquartersCityId), **조직-국가 멤버십**(회원/옵서버/창립국 등), **조직 계층**(산하기구·제휴), **조직-인물 역할**(의장·사무총장 등)도 있으나, 현재 UI에서는 조직 등록 모달에서 위 필드만 입력합니다.

### 행정부처(중앙부처) — 넣을 수 있는 정보

| 필드 | 설명 | 비고 |
|------|------|------|
| **부처명** | name (필수) | 예: 기획재정부, 국정원 |
| **카테고리** | categoryId (필수) | 국방·외교·재정 등 (카테고리 관리에서 추가) |
| **상위 부처** | parentId | 예: 해양수산부 소속 해양경찰청 |
| **썸네일** | thumbnailUrl | 이미지 URL |
| **설립일** | establishedDate | 기관 설립/설치일 |
| **폐지일** | abolishedDate | 통폐합·폐지일 (NULL이면 현존) |
| **후신 부처** | successorId | 개편으로 이어지는 다음 기관 (예: 안기부 → 국정원) |
| **설명** | description | 역할, 담당 업무, 연혁 등 |

### 부처별 사건 — 넣을 수 있는 정보

각 **중앙부처 카드** 안에서 "사건"으로 **몇 년 몇 월 몇 일 뭐 했고**를 기록할 수 있습니다. 제목·기간·유형·설명까지 UI에서 등록/수정 가능하고, 배경·여파·썸네일은 스키마에만 있습니다.
