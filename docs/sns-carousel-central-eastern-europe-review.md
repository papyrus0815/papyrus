- 작성일: 2026-07-14
- 상태: **검토 완료 · 미제작** (스토리 선택·이미지 저작권 확인 대기)
- 요구: 등록된 데이터를 소재로 12세기 말~13세기 초 중·동유럽 역사 SNS 카드뉴스(인스타그램식 카라셀)를 만든다.

## 0. 결론 요약

**소재는 충분하다 — 그것도 정형 데이터가 아니라 서사 필드에서.** 해당 구간(1138~1241)에 핵심 인물 16명이 등록돼 있고, 특히 `death_note`가 사실상 카드 훅 그 자체다(가사바 목욕 피습, 필리시 숲 참살, 연회 급사+독살 의혹, 자비호스트 전사, 190cm 유해 발굴…). 반면 정형 사건 데이터는 1건뿐이라 **"사건 카드"가 아니라 "인물 서사 카드"로 설계해야 한다.**

- **추천 스토리 = C안 「1205년, 자비호스트」**: 로만 므스티슬라비치의 전사를 축으로 폴란드(피아스트)–헝가리(아르파드)–루스(류리크) 삼국이 교차 — 확정한 시대 범위(12세기 말~13세기 초)와 "중·동유럽"이라는 주제 폭에 정확히 맞고, 유일하게 등록된 사건(갈리치아-볼리니아 왕위 계승 전쟁 1205~1245)과도 정합. 카드별 구성 §3.
- **게재 전 필수 정리 10건(§5)**: 공개 콘텐츠로 나가는 순간 데이터 결함이 그대로 노출된다. 특히 **저작 혼잣말 누출**(미에슈코 3세 death_cause "…이번엔 망설임 없이 자연사"), 한/영 전환 오타("shlwhfwnd"=뇌졸중), 성씨 오타(피아스/파이스트) 등.
- **이미지**: 남성 군주는 전원 초상 보유(마테이코풍 역사화 — PD 추정이나 건별 확인 필요 §7-2). **핵심 여성 4인(즈비스와바·살로메아·아그네스·게르트루다)은 이미지 0** — 게르트루다 암살 카드(§3 카드6)는 장면 연출 그래픽으로 대체 필요.

## 4. 대안 아웃라인 (시리즈 2·3편)

- **D안(헝가리 편, 8장)**: ①1163년, 헝가리 왕자가 콘스탄티노폴리스로 보내져 "알렉시오스"가 된다(별칭 사유) → ②비잔틴 황위 후계자까지 올랐다가 → ③귀국·즉위, 안티오키아의 아그네스(→안나)와 혼인(1170, 혼인 노트) → ④190cm의 거인(1848 발굴 death_note) → ⑤아들 임레 vs 언드라시 형제 내전 → ⑥임레의 죽음과 5살 라슬로 3세(death_note) → ⑦언드라시의 시대(십자군 별칭 사유) → ⑧아웃트로. 여성 초상 공백(아그네스)이 여기도 걸림.
- **A안(분열의 기원 편, 9장)**: 1138 유언 → 두 왕비(즈비스와바 근친 관면·살로메아 소공파) → 추방공 vs 계모 연합 → **1145 표트르 브워스토비츠 실명·혀 절단**(최강 훅, 초상 보유) → 1146 파문·추방 → 노공의 실패(1177) → 정의공의 연회 급사(1194) → C안으로 이어지는 브리지.
- **B안(별명 시리즈)**: 표지+별명 6장+아웃트로. 제작비 최소. 단 피아스트 별칭에 reason이 미기입이라 카피는 death_note에서 끌어와야 함(별칭 reason 백필하면 인앱 툴팁도 같이 좋아짐 — §6).

## 6. 공백·보강 백로그 (카드에 쓰고 싶은데 없는 것)

1. **여성 4인 초상 0** (즈비스와바·살로메아·아그네스·게르트루다) — C안 카드6·D안 카드3이 직접 영향. 마테이코 포체트에는 남성 위주라 대안: 동시대 세밀화/인장·실루엣 연출.
2. **언급되나 미등록 인물**: 다닐로·바실코(카드 4·9의 실제 주인공), 볼레스와프 4세(형제 서열의 빈 칸), 즈비그니에프(이복형 내전 — A안 전사), 라슬로 3세·콘스탄차, 벨러 4세. 카드뉴스 자체는 등록 없이 가능하나, 카드→인물 상세로 유입시키는 구조라면 다닐로만이라도 등록 가치.
3. **사건 정형 데이터 빈약**: 유일 사건도 description 0자. 자비호스트 전투(1205)·가사바 회의(1227)·레그니차 전투(1241)·필리시 암살(1213)은 사건으로 등록하면 카드↔인앱 딥링크와 "그 해 한 일"(수장 비교) 지면이 같이 산다.
4. **폴란드 역사국가 미등록** — 카드에 국기/지도 표기를 하려면 필요. [[person-historical-country-as-primary-nationality]] 검토(옵션1 피커 대칭)와 같은 결에서 처리 가능.
5. **피아스트 크라쿠프 세니오라트 재위 0건** — 연표형 카드(누가 언제 크라쿠프를 쥐었나)를 만들려면 필요. 마이그 불요, sovereign_reign 데이터 입력만.
6. **피아스트 별칭 reason 미기입**(6건 중 3건만 있음) — B안 선행 조건이자 인물 상세 별칭 툴팁 품질.

## 7. 제작 파이프라인 옵션 · 결정 대기

### 7-1. 제작 방식
- **(a) 카피덱→디자인 툴 수작업**: §3이 그대로 카피덱. 즉시 착수 가능. **(권장 시작점)**
- **(b) HTML 템플릿(1080×1350)→렌더 캡처**: 등록 초상(`/uploads`)을 직접 참조해 카드 시안을 코드로 뽑는 방식. 시리즈화(D·A안)까지 가면 템플릿 재사용 이득이 커짐. 시안 미리보기는 아티팩트로 먼저 확인 가능.
- **(c) 인앱 "카드 내보내기" 기능**: 인물/사건 상세에서 공유 카드를 생성 — 별도 검토 사안(이번 범위 밖).

### 7-2. 이미지 저작권 (게재 전 게이트)
표본 확인 결과 마테이코 「포체트」 계열(작가 1893년 사망 → PD). 다만 **업로드된 84파일의 출처가 균질하다는 보장이 없으므로**, 카드에 실제 올라갈 ~8장만 건별로 출처·PD 여부 확인 후 게재. 촬영본(사진 저작권)이 아닌 스캔/판화본인지도 확인.

### 7-3. 결정 대기
1. 스토리 선택 — C 단독 vs C→D→A 3연작.
2. §5 데이터 정리를 DB에서 고칠지(권장), 카드 카피에서만 고칠지.
3. 여성 인물 비주얼 처리 방식(실루엣/문장/장면 연출).
4. 다닐로 등 미등록 인물 보강 등록 여부(카드→인앱 유입 설계 시).
